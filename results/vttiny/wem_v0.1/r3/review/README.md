# WEM R3 门内未知候选图像复核

复核覆盖 113 条已通过原生几何门、实际触发的 GMC 门与所有权检查的候选边。所有边的冻结离线标签为 `unknown`，按同分区、同序列、同帧、同轨迹和同检测框去重。背景池取当前 RGB 最大真值 IoU 小于 0.05 的候选。身份池取当前 RGB 最大真值 IoU 至少 0.50、身份判断规则为 `track_identity_unanchored` 的候选，其中包含证据不足与历史身份冲突。

- `WEM_R3_HOLD_BG_021` 所在的 `DJI_0183_2` 轨迹 47 在第 132、140、166、194 帧反复落在屋檐和蓝色区域交界。原图与历史观测中可见同一静态结构，适合人工核对背景轨迹如何持续产生弱候选。
- `WEM_R3_CAL_ID_004` 和 `WEM_R3_CAL_ID_015` 在相邻人影之间出现可能的关联分叉。`WEM_R3_HOLD_ID_004` 当前框与前两帧历史框落在裁边处两个相邻轮廓上，红外配准偏移使判断置信度较低。
- 留出背景池有 10 例仍可能为原目标。`WEM_R3_HOLD_BG_002` 对应 `DJI_0071_2` 第 165 帧，红外中仍有与历史方位连续的暗点。RGB 低重叠候选需要结合原图、截断位置与传感器偏移判读。

113 例均已有模型辅助标签和逐例证据，人工复核完成数为 0。所有发现均限于所列候选，R3 冻结标签和工作点保留原状态，本轮没有运行 R4。
