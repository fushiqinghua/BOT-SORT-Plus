# VT-Tiny-MOT W R4 探索性闭环

完成完整 30 段、12,590 帧的八组回放、TrackEval 评测和 CLEAR 逐帧归因。三段试跑和全量结果分开归档。冻结 YOLO11-M RGB-T 检测、RGB ReID 历史特征及各参考的相机运动补偿输入。需要弱框外观的组使用同一编码器，仅对门内 S0 裁剪提取特征。官方 30 段按开发集解释。

R3 保留 `REJECT_ALL_FALLBACK`。R4 使用预登记网格里的探索点，RGB 余弦下限 0.75、运动下限 0.25、效用下限 0.55、双向竞争间隔 0.05。完整回放沿用同一工作点，人工复核未用于选门槛。[R3 冻结决定](../r3/calibration/README.md)

两套参考在 `DJI_0030_2`、`DJI_0061_2`、`DJI_0327_3` 的关闭、影子、强制拒绝模式通过归档轨迹、原有事件和逐帧状态摘要核验。两套全量关闭组也与归档逐段一致。[三段一致性凭据](smoke/verified.json) · [三段八组试跑](pilot/报告.md) · [全量八组及逐帧结果](full/报告.md)

完整 W 在两套参考上各少漏 59 帧，分别新增 145 和 144 个 FP，换号持平。B 上 HOTA 增加 0.018 个百分点，MOTA 下降 0.048 个百分点。131 次正式提交中，49 次当帧补回，82 次未匹配。未匹配的 82 次中，53 次与任何有效真值的最大 IoU 小于 0.05，29 次位于 0.05 至 0.50 区间。低重叠证据用于定位错误，背景身份仍待独立确认。相比 W-coast，采用弱框坐标再少 3 个漏检、15 个误报，HOTA 增加约 0.009 个百分点。[逐帧 W 提交对照](full/attribution/committed_clear.csv) · [变化的 B 恢复事件](full/attribution/changed_B_events.csv)

原生低阈值、旁路几何和 Coast-only 分别有 19、18、17 段的 HOTA 上升。原生低阈值取得最高 HOTA 和 IDF1，同时增加 2,244 个 FP。旁路几何少漏 508 帧、少 2 次换号，增加 554 个 FP，MOTA 仅降 0.024 个百分点。Coast-only 少漏 931 帧，增加 1,197 个 FP 和 9 次换号。结果支持保留 W 的默认关闭策略。[逐序列配对指标](full/paired_per_sequence.csv)
