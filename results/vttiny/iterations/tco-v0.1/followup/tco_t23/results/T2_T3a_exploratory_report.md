# TCO 探索版 T2 结果与 T3a 软件校验

T2 的 seed 41 三臂拟合、校准和训练侧留出检验均已完成。P3 带历史模型在留出上没有净修复，未通过手册的进入条件，状态 `STOP_T2_INSUFFICIENT_HOLDOUT_INCREMENT`。本轮保留已训练的检查点和冻结校准结果，未输出可用于正式开启回放的选择文件。复种子及全量 T3a 开启回放未启动。

## 数据与隔离

- 使用经授权的代理分组探索方案。官方归档未提供可核验的母视频映射。对官方索引内 34,111 张训练 RGB 和 12,590 张测试 RGB 做 SHA-256 排查，跨划分没有发现字节相同的图像。`DJI_0061_2` 的未索引训练目录重复件在正式训练索引之外。对 85 个有索引的训练片段再按保守组剔除与测试集同组的 11 段。
- 留下 74 段、28,931 帧。拟合、校准、留出分别为 51、11、12 段，代理分组分别为 46、10、10 组。官方测试 30 段未用于拟合、校准或选检查点。冻结检测和 RGB ReID 的权重、行索引与回放来源均通过核验。
- 从真实原生低分阶段导出 32,410 条合规候选边。161 条低 IoU 案例做模型辅助盲审，58 条达到同一目标的补充标注标准，拟合、校准、留出分别为 28、21、9 条。人工复核未代填。校准侧 21 条补充正例中的 20 条来自 `DJI_0067_2`，留出侧比例和可覆盖偏框受小样本限制。

## T2 训练侧留出

以下是 3,959 个可裁剪的原生已配对低分观测，含 3,343 个原本过线正例、9 个原本不过线的确认正例、31 个已知负例及 576 个身份未知例。上下跨线按同一真值的量测 IoU 0.50 判断，未采用修正的观测按原框计入。

| 方法 | 采用修正 | 从低于 0.50 到合格 | 从合格到低于 0.50 | 净修复 | 已知负例采用 |
| --- | ---: | ---: | ---: | ---: | ---: |
| P0 原框 | 0 | 0 | 0 | 0 | 0 |
| P1 几何特征 | 0 | 0 | 0 | 0 | 0 |
| P2 仅当前 RGB | 97 | 0 | 3 | −3 | 1 |
| P3 当前 RGB＋历史 | 66 | 0 | 2 | −2 | 0 |

校准侧 P2、P3 各净修复 1 个，均锁定支持分数至少 0.95、修正框质量至少 0.70、预测质量增量至少 0.005。P1 在预算内未找到有净修复的工作点，冻结为回退。P3 在留出采用的 66 次中，15 次身份标签未知，51 次为确认正例。其确认正例平均 IoU 从 0.745197 降至 0.744904。P2 采用了 1/31 个已知负例，超过预登记的 1% 预算。

P3 在 `DJI_0083_2` 第 328、354 帧生成了能够过线的合法修正，IoU 分别从 0.4893 到 0.5147、从 0.4940 到 0.5351，但预测质量增量仅为 −0.0010、−0.0042，均回退原框。相反，`DJI_0183_2` 第 179、256 帧的预测质量增量为 0.0069、0.0105，修正获准，实际 IoU 分别从 0.5159 降到 0.4865、从 0.5435 降到 0.4819。这四条记录展示了现有质量头无法可靠排序改善与损伤的具体情形。本轮未根据留出结果重选阈值。

## T3a 核验与完整测试集状态

已实现仅在原生低分配对完成后替换该次 KF 量测坐标的接入。固定原始检测行、分数、类别和 RGB ReID，未更改原低分分配和 B 的记忆写入。两个参考均在六段真实序列通过关闭、只记录和强制回退校验。36 个序列运行的轨迹、原有事件与卡尔曼状态链逐字节一致。只记录及强制回退模式分别计算了 P3 输出，均采用 0 次修正。

完整 30 段尚无开启 TCO 的 HOTA、IDF1、MOTA、FP、FN 和 IDSW。关闭组的历史参考见 T0 归档。本轮的留出 IoU 变化描述单次量测，不作为完整跟踪效果。
