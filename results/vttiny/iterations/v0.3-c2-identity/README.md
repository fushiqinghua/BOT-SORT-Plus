# VT-Tiny-MOT 跟踪迭代与消融

完整实验覆盖官方测试集 30 段、12,590 帧，固定 YOLO11-M RGB–红外融合检测、RGB ReID 缓存、SOF 相机运动补偿及 RGB 真值。评测按七类合并取 TrackEval 的 `COMBINED_SEQ`。FP、FN 按目标帧计，IDSW 按换号事件计。该测试集参与过模型选择、门限校准和错因诊断，结果按开发实验解读。

关闭 C2 的位置修正版相对原始 BoT-SORT 提高 HOTA **1.0647** 点、IDF1 **1.7017** 点，少漏 2,860 个目标帧、少换号 44 次，增加 3,082 个误报。短时恢复和两帧外推解释了主要召回收益。和单用 RGB 位置修正相比，红外补位额外减少 7 个 FN 和 7 个 FP。 [逐步贡献](05-position-refinement/stage_comparison.csv)

在相同的位置修正基础上，开启连续低分预热 C2 比原确认记忆版净少漏 95 个目标帧、少换号 5 次，增加 242 个误报。其中 `DJI_0327_3` 贡献了 74 个净补回。相比关闭 C2，低分预热版多 182 个 FN、少 131 个 FP、少 10 次换号，HOTA 少 0.0244 点、IDF1 少 0.0192 点。表中 HOTA 和 IDF1 最高的是关闭 C2 的位置修正版。 [单段与 30 段三组对照](07-low-score-warmup/README.md)
