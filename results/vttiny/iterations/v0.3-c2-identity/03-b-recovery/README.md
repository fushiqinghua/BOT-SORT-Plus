# VT-Tiny-MOT 跟踪修复与全量消融

**建议将 `B_confirmed_early` 作为 C2 后续研究版本，继续保留 `B_ref` 为对照。** 它让 B 的恢复记忆库有条件地学习近期外观，同时允许有充分证据的候选提前一帧接回旧 ID。沿用每个输出框都有当帧检测支持的口径，HOTA、IDF1、AssA、MOTA 均超过 B 参考。误报减少 179 个，换号减少 12 次，漏检增加 55 个。最高 HOTA 来自另一配置 `B_early_motion2`，它允许无检测匹配时输出最多两帧运动预测，误报代价明显更高。

## 二、实现和可归因的变化

**有条件地更新 B 的近期外观。** 保留 C2 私有长期锚点的严格写入，BoT-SORT 原生外观模板沿用 B 参考的正常更新。B 的恢复库继续写入 C2 已确认的观测。若 C2 给出“历史冲突”，只有当前帧和紧邻上一帧均为同轨高分匹配、RGB 质量合格、几何代价均不高于 0.50、无竞争或最近竞争者的代价差至少为 0.10，且两帧 RGB 余弦距离不高于 0.40，才额外允许 B 库写入。重激活当帧不能为这条规则提供连续支持。门限、距离和质量均使用推理时可得信息。

**把第三帧确认改为有条件的第二帧确认。** 对已经丢失的轨迹，原 B 通常等待候选满足三次观测。新规则只在两次候选观测连续、两帧都通过原有空间与外观检查、最差几何代价不高于 0.42、最差外观代价不高于 0.55 时允许提前恢复。仍执行双向竞争检查、一对一分配与原总代价门限。没有达到提前确认条件的候选仍可走原三次观测路径。全量中 `early_moderate` 有 301 次二帧恢复，`confirmed_early` 有 177 次。与只改记忆的对照相比，组合版 HOTA 再升 0.109、IDF1 再升 0.182，FN 减少 135 个。[恢复事件统计](evidence/early_counts.json)

**高召回配置允许报告短时运动预测。** 仅对最近三个连续检测输出有足够置信度、近期运动预测和检测框吻合的旧轨迹，在没有当帧匹配时报告最多两帧预测框。依据原在线 Kalman 和 SOF 结果，限制越界和与已输出框重叠；预测框不写入外观库、不推进轨迹状态、不作为后续匹配观测。去掉预测框，30 份轨迹逐字节恢复到各自的无预测版本。`early_motion2` 相对 `early_moderate` 新覆盖 452 个真实目标帧，也多了 563 个 FP；相对 B 参考 HOTA +0.196、IDF1 +0.277、FP +753、FN −670、IDSW −5。保留 C2 近期记忆的 `confirmed_early_motion2` 则能兼顾两个典型目标，相对 B 参考 HOTA +0.134、IDF1 +0.163、FP +381、FN −392、IDSW −10。[运动输出逐帧来源与匹配](evidence/motion/motion_events.csv) · [删除预测框后的复核](evidence/motion/motion_audit.json)

本轮在 3 个参考配置之外实测 22 个候选，均保留在结果表中。给双模板增加回退，在开放写入条件下得到与原 C2 仅关联校准相同的轨迹；严格门控后再回退也未恢复足够覆盖。加快外观均值更新、只隔离恢复当帧或仅放松轻度外观矛盾均未超过 B 参考。按历史峰值低于 0.60 限制恢复的两组不改变输出：该实验的原生新轨起始检测本来就至少为 0.60，这项规则没有形成有效对照。把旧轨已输出的历史与完整的起轨观测分开，是解释该结果的前提。[全部 25 组联合指标](evidence/all_methods.csv) · [逐序列独立计数](evidence/clear_verified_counts.csv)
