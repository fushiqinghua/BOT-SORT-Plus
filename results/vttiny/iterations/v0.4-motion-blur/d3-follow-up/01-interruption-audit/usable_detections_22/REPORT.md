# D3 有可用检测的 22 次首次中断

在 `B_early_moderate` 的 13 个测试序列上复查了归档 D3 队列中的全部 22 次首次中断。每次中断当帧均有一个可唯一归属到目标的 RGB 检测。15 次中断的直接原因是原轨迹与该检测的关联代价超过门限，4 次已关联到正确检测但输出框与真值的 IoU 低于 0.5，3 次原轨迹更新到了另一个身份未定的检测。22 次当帧在预测前均为 `Tracked`，距最近一次真实观测均为 1 帧。

| 首次中断当帧发生的事 | 次数 | 证据 |
| --- | ---: | --- |
| 原 ID 未更新，低分几何关联超门限 | 12 | 低分阶段要求预测框与检测框 IoU 至少 0.5。12 个实际取值介于 0.225 和 0.494。 |
| 原 ID 未更新，高分关联超门限 | 3 | 预测框与检测框 IoU 介于 0.122 和 0.174，未通过外观融合的几何近邻条件。原始 RGB 余弦距离介于 0.180 和 0.248。最终代价介于 0.826 和 0.878，超过 0.8。三个检测后来均启动了新轨迹。 |
| 原 ID 接受正确检测，输出框 IoU 低于 0.5 | 4 | 检测框对真值的 IoU 为 0.5002–0.5248，输出框为 0.4611–0.4975。Kalman 更新在四帧均改善了更新前预测框的 IoU。关联成功后，输出依然未达到诊断阈值。 |
| 原 ID 接受另一身份未定的低分检测 | 3 | 两次正确检测的配对代价超过 0.5，一次代价为 0.4947 且有另一低分检测被接受。三个可用的正确检测均未被任何轨迹消费。 |

15 次未更新的原轨迹均在当帧转为 `Lost`。其中 14 次可用检测对应的 B 检查记录为 `outside_retention`。另一次为 `DJI_0309_4` 第 98 帧，预测框与可用检测的 IoU 为 0.4945，候选生成事件标注 `competing_links`，该检测未产生相应的 B 检查记录。

## 诊断范围与复核

样本沿用归档 D3 的口径。B 恢复后有完整 10 帧窗口，分析窗口内首次无法维持原 ID 和真值的诊断对应的当帧。可用检测按原诊断口径要求进入高分或低分关联阶段，与该目标的 IoU 至少 0.5，并通过一对一对应和 0.05 的歧义间隔检查。首次中断距恢复为 1–9 帧，距最近一次真实观测均为 1 帧。这里的数量是 D3 窗口事件计数。

先读取官方 RGB 真值、归档 MOT、检测及轨迹事件，核验 22 个样本及输入哈希，再以冻结的 `B_early_moderate` 在相关 13 个序列上重放，记录原 ID 和候选检测在关联阶段的实际代价。真值用于离线定位和分析。13 个序列的 MOT 输出、原始事件流与解码 RGB 像素 SHA256 均与归档一致。全局运动补偿的例子显示补偿前后的当帧几何变化，未运行关闭补偿的反事实实验。

`result/candidate_decisions.csv` 是逐例审计表，包含原 ID、GT ID、检测索引、接受阶段、实际代价和几何指标。`result/diagnosis.json` 包含原事件、B 保留检查和重放代价。`result/observed_cases.json` 保留离线提取的当帧证据，`result/reprobe_parity.json` 记录 13 个序列的复跑一致性，`result/TRANSFER_SHA256.json` 记录本地下载校验值。`audit.py` 与 `launch.py` 是复查脚本。
