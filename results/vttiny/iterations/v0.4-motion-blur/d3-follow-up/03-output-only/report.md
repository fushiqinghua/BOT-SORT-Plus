# VT-Tiny-MOT 低分只补帧验证

实验日期 2026-11-26。对照为冻结的 `B_early_moderate`，已有低分续接为 `B_postlow_v1`，本轮为 `B_postlow_output_v1`。先在 `DJI_0339_2`、`DJI_0327_3` 验证，再固定代码重放官方测试集 30 段、12,590 帧。三组使用相同的检测缓存、RGB ReID 特征、解码图像、原有跟踪参数和官方真值。评测锁定 TrackEval `12c8791b303e0a0b50f753af204249e622d0281a`。

## 实现与校验

已有低分版用命中的低分框更新原轨迹。本轮从原生流程读取当前预测、原生失配、上一帧实测、最近一次 B 恢复及已有匹配框。写文件时给符合条件的低分检测增加一行，使用同一轨迹 ID、原始检测坐标和分数。之后的卡尔曼滤波、轨迹生命周期、候选池、RGB 外观和 B 恢复继续使用原生状态。

本轮沿用 `[0.05, 0.10)` 分数范围、预测 IoU ≥ 0.50、两边候选优势均 ≥ 0.10、B 恢复后 1–3 帧及每次恢复至多补两帧的规则。发出前检查最终原生输出，避免同 ID 或大幅重合。上一帧必须有原生实测，补出的行只影响当帧输出。轨迹文件中新增行和 `output_only_low` 事件一一对应。核对时逐字节比较剔除新增行的 MOT 和剔除专用事件的原始跟踪事件，包括 B 恢复和候选检查。

- **DJI_0339_2**。相比更新状态的低分版，误报减少 203 个，压掉此前相对基线新增误报的 95.3%。只补帧仍直接输出 10 个误报，漏检和换号持平。其余原生轨迹与 B 恢复事件均与基线相同。
- **DJI_0327_3**。相比更新状态的低分版，误报少 19 个，漏检多 30 个。相比冻结基线，误报多 22 个，漏检少 33 个。24 个固定首次中断帧以原 ID 补回，保留上一版成功的全部 23 例，并新增 GT 70 的第 268 帧。恢复后连续 3、5、10 帧保持原 ID 的窗口为 59／41／30 个，更新状态的低分版为 67／46／33 个，冻结 B 为 52／41／30 个。GT 76 第 181 帧恢复后，两个低分版都补到第 182 帧，只有更新状态的版本能接着补第 183 帧。上一轮报告误录了这两帧的检测分数，原始事件中的分数是 0.095828 和 0.063791。


两段试跑的原生 CLEAR 匹配关系均保持不变。DJI_0327_3 多出的 1 次换号来自 GT 89。CLEAR 将第 232 帧补出的 ID 41 和第 289 帧补出的 ID 48 记作该目标相邻的两次有效命中，跨越中间缺失帧计为一次换号。

21 段共增加 191 行。依照官方 CLEAR 逐行复核，其中 72 行命中真值、119 行是误报。72 个命中中，61 个的上一帧实测检测和原生轨迹输出均支持同一 GT，另 11 个命中的身份依据不足。去除新增行与专用诊断事件后，30 段的 MOT 和事件均与冻结基线逐字节一致。全部原生框的 CLEAR 分配也完全相同。试跑和全量使用相同实现哈希。最终占用检查未拦截任何候选。

MOTA 相比上一版收回 0.1202 个百分点，同时保留原版相对冻结 B 的 72／138 个净漏检改善。全量的两次新增换号来自评测器把补帧命中纳入同一 GT 的身份历史。除两段试跑中记录的 `DJI_0327_3` GT 89 外，`DJI_0061_2` 的 GT 30 在第 152 帧的 ID 151 和第 171 帧原有的 ID 95 之间，多了第 169 帧补出的 ID 177，产生一个额外的身份切换。

## 固定事件对照

使用第一轮 D3 冻结的 287 个恢复窗口，其中 210 个发生首次中断。依据官方 GT 核实恢复前和恢复时的轨迹身份，按 IoU ≥ 0.50 在原中断帧核实是否补回同一 ID，并比较恢复后逐帧持续命中 3、5、10 帧的数量。

| 方法 | 首次中断帧原 ID（210 例） | 低于原分数线（89 例） | 连续 3 帧 | 连续 5 帧 | 连续 10 帧 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 冻结 B | 0 | 0 | 152 | 122 | 77 |
| 更新状态的低分版 | 44 | 43 | 182 | 136 | 86 |
| 只补帧 | 49 | 49 | 164 | 124 | 78 |

只补帧留住了 44 例中的 43 例，另外补回 6 例。剔除补帧后，只补帧版的原生连续计数仍为基线的 152／122／77。

- **新增例**。在 `DJI_0051_2`，GT 2 的 ID 28 在第 491 帧由 B 恢复，第 492、493 帧正常匹配，第 494 帧追加低分框补回原中断（检测分数 0.07143，和预测的 IoU 为 0.59538）。上一版更早改变了状态，第 491 帧走原生低分关联，第 494 帧缺少近期 B 恢复依据。
- **唯一丢失例**。在 `DJI_0303_2` 的第 58 帧，两个版本都给 GT 1 的 ID 2 选择了检测索引 5。更新状态后的输出与 GT 的 IoU 是 0.52930，直接写出的低分框是 0.47351。检测选择与 ID 相同，差异来自框坐标未达到 0.50 真值核验门限。

只补帧验证了将低分输出与跟踪状态隔离可以阻断误报传播，代价是无法由该输出触发下一帧续接。相对冻结 B，HOTA 和 IDF1 略增，MOTA 略降，仍有 119 个直接误报。冻结 B 继续作为正式基线，只补帧版作为本轮有效的诊断消融。

两个目标序列和固定事件来自同一测试集的历史诊断。本轮在试跑与全量间保持规则和实现哈希固定，结论按回顾性消融解释。压缩包保留三组轨迹与事件、试跑及全量指标、原生轨迹一致性证明、固定事件对照、实测 GT 核验和实现脚本。
