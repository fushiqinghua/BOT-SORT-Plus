# VT-Tiny-MOT 低分补帧的误报溯源与筛选

实验日期 2026-11-26。输入为官方测试 30 段上的冻结对照 `B_early_moderate`、只补帧版 `B_postlow_output_v1` 的 191 行新增输出及相应检测缓存和事件。使用相同的官方真值和 TrackEval `12c8791b303e0a0b50f753af204249e622d0281a`。原始 191 行中有 119 个 CLEAR 误报和 72 个命中真值的框。

## 119 个误报的来源

逐个读取候选当帧、同一原生轨迹 ID 的历史实测检测与原生输出，并用官方真值核对。持续背景类的诊断条件为至少 3 次原生实测、历史所有实测和输出以及当前补帧框与各帧真值的最大 IoU 均小于 0.10。该条件仅用于事后归因。

| 主要原因 | 数量 | 真值证据 |
| --- | ---: | --- |
| 既有背景轨迹 | 45 | 涉及 7 段、20 条轨迹。41 个案例的当前及历史 IoU 全为 0。 |
| 同一目标定位不过线 | 44 | 当前最接近的真值仍是该轨迹最近确认的 GT，IoU 在 0.10 至 0.50 之间。 |
| 轨迹曾命中真值，补框位置偏离或接近别的目标 | 18 | 有历史真值支持，当帧框偏离原目标。 |
| 历史身份未确认，当前与某目标弱重叠 | 8 | 仅能确定当前位置关系。 |
| 历史身份未确认，当前几乎无重叠 | 3 | 证据不足以按严格历史条件归为背景。 |
| 分配竞争 | 1 | 当前框与真值 IoU 达到 0.50，真值由其他轨迹匹配。 |

把背景诊断的最大 IoU 上限设为 0.05、0.10、0.20，分别得到 45、45、46 例。把最少实测次数设为 1、3、5 帧，计数相同。

- `DJI_0339_2` 的 10 个新增误报全部来自背景轨迹，ID 2 占 8 个，ID 6 占 2 个。ID 2 在第 48 帧对预测框的 IoU 是 0.9008，但对真值为 0，且此前 37 次实测检测和 36 次原生输出也全部与同期真值零重叠。该轨迹历史原生输出最高分达 0.7177。较高的历史检测分和预测一致性也会出现在持续背景轨迹上。
- `DJI_0327_3` 的 22 个误报中，21 个与最近目标的 IoU 位于 0.25 至 0.50。第 316 帧的 ID 62 延续了上一帧的 GT 217，预测 IoU 为 0.9156，原始低分框对 GT 的 IoU 为 0.4945，低于评测的 0.50。
- `DJI_0073_3` 第 92 帧，补框 ID 63 对 GT 20 的 IoU 为 0.5437，同帧原生 ID 46 则达到 0.8014。两预测框间 IoU 仅为 0.4473，因此通过现有的 0.50 占用检查，评测将 GT 20 分配给原生 ID 46。

## 72 个命中真值的补框

72 个命中的 GT 当帧均缺失于冻结基线的 CLEAR 匹配。61 个与上一帧实测检测和原生轨迹输出都对应同一个 GT，9 个仅与更早的最后一次 CLEAR 真值关联一致，2 个与该轨迹最近确认的 GT 不同。后两例是 `DJI_0061_2` 第 169 帧（轨迹 177 最近确认 GT 90，当前命中 GT 30）和 `DJI_0327_3` 第 289 帧（轨迹 48 最近确认 GT 92，当前命中 GT 89）。这两例计入检测命中，同时改变了该 GT 的评测身份历史。固定 D3 事件另按恢复前与恢复帧的同一 GT 验证，原版 49 个首次中断原 ID 补回。

## 只在输出端筛选

用当前补框及此前同一 ID 的原生历史生成筛选掩码，真值只用于事后评估。筛选时仅移除带专用标记的原始补帧行及其发出事件。用相同真值和相同版本 TrackEval 重新评估全量，并重算 287 个冻结 D3 窗口。所有方案剔除补帧后，原生 MOT 和 B 相关事件均仍与基线逐字节一致。原生框在 CLEAR 中的真值分配也一致。

- **短边门限**。去掉当前低分框短边小于 8 像素的补帧。
- **小框且近静止**。在短边条件之外，要求过去 15 帧至少有 5 个原生输出，且这些框中心之间的最大距离不超过上一原生框对角线的 0.5 倍。位置来自原始图像坐标。
- **再要求反复恢复**。在小框近静止之外，同一 ID 在过去 15 帧至少发生两次 B 恢复。

小框且近静止去掉 35 个误报，其中 17 个来自既有背景，7 个是同一目标定位不过线，6 个发生在曾命中 GT 但当前偏离的轨迹，另 5 个的历史身份未确认。它在 `DJI_0339_2` 去掉了 7 个误报，在 `DJI_0327_3` 去掉 4 个误报并保留 23／24 个原 ID 补回。仅计其余 28 段的逐行核验结果，仍去掉 24 个误报，保留 34／39 个正确框和 23／25 个原 ID 补回。

要求反复恢复的方案去掉的唯一真实补帧为 `DJI_0141_2` 第 336 帧 ID 17 对 GT 18。原始框真值 IoU 0.754，过去 15 帧的最大中心位移仅为上一框对角线的 0.070，期间 B 恢复了 4 次。真实的远距离小目标也能触发这类规则。

## 结论

小框且近静止是这三组中去除误报和保留原 ID 的折中方案，保留 46／49 次原 ID 补回并去掉 35／119 个误报。它仍留下 28／45 个确认的背景误报，MOTA 比冻结 B 低 0.0106 个百分点。当前继续使用冻结 B 作为正式基线。组合规则是在考察同一测试集上单条件的表现后确定，结果属于探索性消融。分析时生成输出掩码并重新评测，筛选逻辑保持在输出端。
