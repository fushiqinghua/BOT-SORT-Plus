# B 与自适应 GMC 的组合、错因与长间隔重连

`B_early_moderate` 与 `dual_low` 组合后，相对单 B 少了 39 个漏检、16 次换号，多了 105 个误报。长间隔重连修正 `evidence_both` 将相对单 B 的净增误报从 105 个压到 2 个，换号比单 B 少 22 次。进一步暂存原 ID 的方案补回了部分漏检，整体指标变化很小，因此保留 `evidence_both` 为主版本，`pending_guarded` 作为消融对照。

## 完整 30 段对照

在 VT-Tiny-MOT 官方测试集的 30 段、12,590 帧上运行。各组使用相同的 YOLO11-M RGB–T 检测、RGB ReID 缓存和 RGB 图像，保留原版卡尔曼滤波。按官方 RGB 真值合并类别，使用 TrackEval `COMBINED_SEQ` 汇总，指标差值以百分点计。

## 两段错因与重连修正

- **`DJI_0030_2` 净增 67 个误报。** 第 409 帧的 LightGlue 补偿改变了背景轨迹 ID 4 的状态。第 427 帧，ID 4 以 0.6491 的代价通过 B 的 0.65 门限，接走真值 4，触发从原 ID 7 到 ID 4 的换号。重新激活的 ID 4 之后继续输出大量误报。整段重放时，仅把第 409 帧 ID 4 的状态补偿换回原生，误报即从 1,347 降至 1,283，换号从 1 降至 0。
- **`DJI_0169_3` 净增 28 个误报。** 第 174 帧原生高分关联接回 ID 12，受第 149 帧 B 恢复及后续补偿共同影响，该轨迹后续新增 22 个误报。第 108 帧 B 接回了与现有轨迹争同一真值的 ID 7，真值 6 先切到 ID 7，后切回 ID 6。单独阻断第 108 帧的恢复，消除了两次额外换号，误报总数仍为 1,539。
- **`evidence_both` 的取舍。** 对受 GMC 改动影响的长间隔重连，在 B 恢复和原生高分找回两处收紧关联门限，并暂缓只有低分检测且缺少有效外观支持的 B 恢复。相对原组合，误报少 103 个、换号少 6 次、漏检多 9 个，MOTA 提高 0.05563 点。相对单 B，误报仅多 2 个，漏检少 30 个、换号少 22 次。

## 暂存原 ID 后再确认

`pending_guarded` 在暂缓重连期间保存原身份，最多等待 30 帧。后续观测通过几何和观测证据检查后，用原 ID 在确认当帧接回，并继续约束低分续接。`DJI_0030_2` 的真值 4 在第 416 帧用原 ID 7 正确接回，输出框 IoU 为 0.5505。第 417 帧的检测分数 0.24547 略低于保护门槛 0.24653，所以只补回一帧。先前移除的 67 个误报全部保住。放宽连续低分确认的对照接回了背景 ID 4，使其中 51 个误报重新出现。

全量共确认 5 次接回，3 次找回同一真值，另外 2 次在接回当帧计为误报，均发生在 `DJI_0169_3`。相比 `evidence_both`，受保护版共多 6 个误报，少 13 个漏检及 1 次换号，HOTA 提高 0.00431 点。另有 27 段轨迹文件逐字节一致。[暂存实验与对照](pending/原ID暂存与接回实验.md) · [30 段逐序列指标](pending/30段_逐序列对照.csv) · [五次接回及后续十帧核验](pending/full/guarded_release_context.csv)
