# W R4.2 逐帧错因分析

基于同一份官方真值和固定 TrackEval CLEAR 匹配。逐帧账本的 FP、FN、IDSW 与正式评测一致。未匹配 FP 是评测结果，图像中实际物体身份需要独立复核。下文 `detN` 是冻结检测中的行索引。

## DJI_0339_2 · 降低原生低分阈值

轨迹 ID 2 在第 48 帧接到 `det7`，得分 0.0680。W0 以弱框补一次，`lower_low` 走原生低分，两个输出均在当帧判为 FP。第 49–52 帧，`lower_low` 继续由原生低分延续 ID 2，四帧输出均与现有真值无重叠。W0 同段没有该 ID 输出。这一差异与原生低分反复消费原阈值以下的框相符。

| 帧 | 检测行 | 冻结检测分数 | W0 的 ID 2 | 降阈值组的 ID 2 |
| ---: | ---: | ---: | --- | --- |
| 48 | 7 | 0.0680 | 弱框 FP | 低分 FP |
| 49 | 3 | 0.0973 | 无输出 | 低分 FP |
| 50 | 4 | 0.0925 | 无输出 | 低分 FP |
| 51 | 5 | 0.0856 | 无输出 | 低分 FP |
| 52 | 5 | 0.0775 | 无输出 | 低分 FP |
| 53 | 4 | 0.2000 | 无输出 | 低分 FP |

整段 FP 从 1,172 增至 1,507，净增 335，FN 为 1,389，换号为 0。第 53 帧的检测分数已经超过原低分阈值，说明此前轨迹续接的变化也会影响后续较高分的检测。 [逐帧账本](lower_low_DJI_0339_2.json)

## DJI_0339_2 · 放宽锚点约束

两组 ID 2 在第 95 帧均接纳弱框，第 96 帧均完成原生低分续接。第 97 帧只有一帧常规锚点历史。放宽组的 `anchor_not_ready` 为真，两项锚点几何不一致标记均为假。它接纳 `det4`，原始分数 0.0640，正式预测 IoU 0.7200，输出与真值的最大 IoU 为 0。W0 在第 97–98 帧无 ID 2 输出，第 99 帧才由 B 恢复该 ID。放宽组由第 97 帧的弱框继续到第 98、99 帧的原生低分关联，均判为 FP。

整段放宽组由 1,172 增至 1,384 个 FP，净增 212，FN 持平。同帧检测行对齐显示这 212 个 FP 均来自 ID 2，来源为 28 次弱框、157 次原生低分、20 次 B 恢复和 7 次原生高分。第 99 帧两组同一检测行均为 FP，仅输出来源不同。该例明确触及锚点成熟度，全量消融同时改变了三项锚点约束。 [逐帧账本](relaxed_anchor_DJI_0339_2.json)

## DJI_0327_3 · 弱框正式状态反馈

GT16／ID55 在第 228 帧的两个变体都使用 `det42`，原始分数 0.0747。W0 输出对真值的 IoU 为 0.386，`emit_only` 为 0.387，均判为 FP。W0 写入正式状态，第 229 帧仍是原生低分 FP，第 230–236 帧用同一 ID 连续命中 GT16。第 237 帧三组均由原生高分检测 `det20` 命中 ID55。

| 帧 | BG_off | BG_W0 | BG_W0_emit_only |
| --- | --- | --- | --- |
| 228 | GT16 漏检 | 弱输出 FP，正式状态更新 | 弱输出 FP，正式状态未更新 |
| 229 | GT16 漏检 | 原生低分 FP | GT16 漏检 |
| 230–236 | 全部漏检 | 七帧均由原生低分匹配到 ID55 | 全部漏检 |
| 237 | 高分接回 ID55 | 高分匹配 ID55 | 高分接回 ID55 |

`emit_only` 的原生事件与正式状态链和关闭组一致。该例说明当帧未匹配的弱观测进入正式轨迹后仍可能帮助后续覆盖。W0 与 `emit_only` 比较的是完整的状态反馈，涉及轨迹生命周期和后续关联。 [逐帧账本](state_feedback_DJI_0327_3.json)
