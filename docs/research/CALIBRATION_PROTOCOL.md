# M2 测量噪声校准与数据划分

本文件对应 `botsort_research/calibration.py`。校准过程可以读取标注，跟踪预测过程不读取标注。校准结果只输出全局噪声参数、输入文件哈希和统计信息，不向跟踪器传入某一帧的真实位置或身份。

## 1. 划分必须先于校准

自动划分按 `DJI_数字` 录像前缀分组，同一段录像的不同切片一起进入 calibration 或 evaluation；不允许逐帧随机划分。非 DJI 名称默认整段序列为一个组。划分由 seed 和组名哈希决定，输入文件排列不影响结果。

这只是防止明显泄漏的最小措施。若不同录像属于同一航次、地点或连续拍摄时段，需要人工合并这些组，再建立划分；录像文件名本身不能证明样本独立。

**仓库归档的官方 test 已经用于先前模型与检查点选择。本分支自动生成的划分标记为 `retrospective_development_only`，不能把重新切出来的 evaluation 称为从未使用过的独立测试集。** 本轮可用于研究诊断、模块选择和内部对照。论文中的独立泛化实验需要另行冻结新录像或之前未使用的数据，所有阈值、模型和噪声参数确定后再评估。

划分 JSON 的必要字段：

```json
{
  "schema_version": 1,
  "interpretation": "retrospective_development_only",
  "grouping": "DJI flight prefix",
  "seed": 0,
  "calibration": ["DJI_0028_3"],
  "evaluation": ["DJI_0030_2"]
}
```

以上只说明格式，不是完整实验划分。`validate_split` 会拒绝重复序列、两部分重叠、同一录像前缀跨组、空分区和不存在的检测缓存。阈值选择只能使用 calibration 或进一步从 calibration 划出的内部验证录像。比较多套参数后在 evaluation 挑出最好的一套，该 evaluation 也参与了模型选择。

## 2. 不只用 IoU ≥ 0.5 的检测拟合噪声

微小目标移动几个像素后，检测框与真实框可能不相交。如果只采集 IoU ≥ 0.5 的框，恰好把希望建模的误差排除掉。

本实现以检测和官方 RGB 标注构造候选，使用如下固定规则：

- 检测置信度严格大于 0.1；低于此值的缓存用于其他检测诊断，不属于当前跟踪器的有效输入。
- 中心偏差分别除以两框对应宽、高与 6 像素的最大值，二维归一化距离不超过 1.5。
- 两框宽、高的比例分别不超过 4 倍。
- 代价为归一化中心距离加 0.25 倍宽、高绝对对数比例之和，进行带拒绝选项的一对一分配。
- 同一检测存在相近的其他 GT，或同一 GT 存在相近的其他检测时，要求替代候选的代价至少高 0.2，否则排除该对。

这些规则用于离线收集较明确的残差样本，**不是新跟踪算法的在线门限**。它们仍然带来选择偏差：排除了拥挤目标、大误差检测和歧义样本，不能声称得到了所有漏检、虚警条件下的真实误差分布。输出中保留候选、分配、歧义排除、最终保留数量，以及目标尺度和置信度分层计数。门限应在校准部分做敏感性检查，不能看到 evaluation 结果后随意修改。

## 3. 噪声模型与拟合

使用中心和宽高测量 `z=(cx,cy,w,h)`。令残差 `r=z_det-z_gt`，对应尺度 `d=(w,h,w,h)`，每个轴拟合：

\[
R_{kk}=a_k+b_k d_k^2+c_k(1-s)^2,\qquad a_k,b_k,c_k\geq 0.
\]

对 `r_k²` 在 `[1,d_k²,(1-s)²]` 上进行非负最小二乘。设计矩阵先按列尺度归一化，拟合后再还原；写入配置的 `floor_std`、`size_scale`、`score_scale` 分别为这些非负系数的平方根。模型的单位与原图像素一致，不使用网络 resize 后的坐标。

```json
{
  "mode": "calibrated",
  "floor_std": [1.0, 1.0, 1.5, 1.5],
  "size_scale": [0.05, 0.05, 0.05, 0.05],
  "score_scale": [2.0, 2.0, 3.0, 3.0],
  "min_variance": 0.000001
}
```

这里的数值仅展示文件格式，不是本仓库数据的拟合结果。真正输出包含顶层 `noise`、`provenance`、`diagnostics` 三项；跟踪器使用其中的 `noise`，同时实验记录必须保留完整文件及其哈希。

每条序列最多均匀蓄水池抽样 20,000 对，固定 seed，防止一个特别长的序列无限主导拟合；这不是每个序列严格等权。至少需要 100 个明确匹配样本，数量不足会报错，不会自动借用 evaluation 数据。对于低置信度、小目标等分层样本严重不足的情况，即使总样本数够，也只能把校准视为试验性参数。

## 4. 如何解读输出

输出包括各轴平均残差、中位残差、RMSE、标准化残差均方根、设计矩阵秩和条件数。四维标准化残差平方和不超过 9.4877 的比例，是**已选校准样本内的检测残差覆盖率**；它不是线上跟踪创新协方差 `S=HPHᵀ+R` 的覆盖率，也不是在独立数据上的 95% 校准保证。

较大的残差均值说明存在系统偏差，本版本只拟合二阶矩，未加入偏差校正。拟合中的残差也包含标注误差；不能把这些系数解释为纯检测器噪声或纯相机噪声。对角高斯、零均值和仅依赖尺度、置信度都是待验证假设。

相邻帧误差高度相关，因此 10,000 对检测不能视为 10,000 个独立样本。比较或区间估计应以录像组为单位。设计矩阵秩不足会明确记录：例如所有目标尺寸和置信度几乎相同，三个系数不能分别识别，不应从这些系数构造物理解释。

## 5. 本轮可复核的顺序

1. 冻结检测缓存、GT 坐标系、划分清单及基线版本。
2. 跑原生无 ReID 的 BoT-SORT 对照，确保新运行入口可以复现旧轨迹。
3. 仅在 calibration 上拟合噪声并检查残差、样本覆盖和稀疏分层。
4. 固定关联门限、未匹配代价和噪声参数，在 evaluation 比较原生 IoU、NLL + 原噪声、NLL + 像素下限、NLL + 校准噪声。
5. 联合检查 HOTA、AssA、IDF1、FP、FN、IDSW 和逐序列失败案例。仅减少 IDSW 但扩大虚警或漏检不能直接认定改进有效。
6. 在新冻结的独立录像上再做最终验证；保存所有运行 manifest，不覆盖先前结果。

脚本执行入口与完整参数见本目录的实验运行说明。校准模块可直接调用 `build_split`、`validate_split`、`select_pairs`、`fit_noise_model`、`calibrate`，便于单独核查。
