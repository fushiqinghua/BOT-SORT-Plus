# VT-Tiny-MOT · M2 概率关联与 M1 / M3 诊断第一轮

**原生无 ReID 的 BoT-SORT 仍作为直接对照。** M2 人工噪声下限组提升了关联指标，同时增加误报与漏检。M1 开关实验证实 SOF 对整体跟踪有贡献，并定位到受补偿影响方向相反的序列。M3 在现有高分 RGB 特征中测得身份区分信号，低分阶段的特征覆盖仍为零。

## 回放与评测口径

- 源码提交为 `850b9940027f788e811ea670a528273f23219b12`。在服务器 `redetr` 内复用了冻结 BoxMOT 和 TrackEval。缓存和图像预检、55 项测试均通过。
- 原生 `native_iou` 在 30 段共 12,590 帧回放出 73,506 条轨迹记录，全部与归档 `botsort_no_reid` 逐帧一致，绝对误差容限为 `1e-6`。21 段评估中的原生轨迹与本次 30 段回放对应文件的 SHA-256 逐一相同。
- 沿用预先提交的录像分组划分，9 段、2,759 帧用于校准，21 段、9,831 帧用于比较。原官方测试集参与过历史选模。本轮是回顾性开发实验，评测合并七类目标并使用官方 RGB 坐标真值。跟踪回放只读取冻结检测和图像，离线校准与诊断读取标注。
- 21 段评估包括空 GT 的 `DJI_0325_2`。汇总来自 TrackEval 的 `COMBINED_SEQ`。M2 四组与 SOF 关闭组的序列、帧数、检测缓存、图像清单和真值指纹均一致。

9 段校准保留 35,045 对检测框与真值框。四轴 `cx/cy/w/h` 残差 RMSE 为 1.493 / 1.331 / 2.647 / 2.230 像素。<8 像素检测框贡献 8,056 对。已选校准样本的四维标准化检测残差覆盖率为 93.93%。拟合参数与分层样本量见 `m2_noise.json`。回放使用校准前提交的关联与拒配配置。

在原生 (R) 下替换两个关联阶段，HOTA 降低 0.423 点，换号增加 82 次。人工噪声下限组的 AssA 提高 1.261 点、IDF1 提高 0.405 点、换号减少 40 次，FP 增加 14.2%，FN 增加 479。<8 像素分组补回 315 个真值目标帧，同时丢失 559 个原本匹配的目标帧，净增 244 个漏检。该组 9 段 HOTA 上升、11 段下降、1 段持平。`DJI_0277_2` 提高 8.652 点且减少 7 次换号，`DJI_0309_4` 增加 207 个误报和 117 个漏检。

### 人工噪声下限组的误报对齐

用 M2 匹配日志的检测索引以及帧内唯一的检测分数回溯两个方法的输出。按同帧、同一源检测比较两组的 CLEAR 结果，全部误报计数与官方评估吻合。

| 误报对应的源检测 | 事件数 |
|---|---:|
| 两组均为误报 | 7,044 |
| 原生为正确匹配，M2 变为误报 | 1,171 |
| 原生没有输出该检测，M2 输出为误报 | 739 |
| 原生为误报，M2 不再产生对应该检测的误报 | 797 |

M2 新产生 1,910 个误报，同时消除 797 个，净增 1,113 个。由原生正确匹配转成误报的 1,171 条中，957 条源检测与某真值框的最大 IoU ≥0.5，而 M2 的输出框与所有真值的最大 IoU 均 <0.5。原生未输出的 739 条新增误报中，492 条来自第二阶段低分匹配，其中 383 条源检测和输出框都没有达到 IoU 0.5。两类现象分别指向关联及滤波后的框定位损失、低分观测延续产生的误报。诊断按可观测结果归类，单帧轨迹配对竞争和历史轨迹状态均可能影响来源。

## M1 · SOF 运动补偿

关闭 SOF 后 HOTA 降低 0.943 点、IDF1 降低 1.759 点，漏检增加 542 个、换号增加 86 次。最小尺寸分组占新增漏检的 293 个。`DJI_0277_2` 和 `DJI_0303_2` 关闭后 HOTA 分别下降 20.460 和 19.074 点，`DJI_0109_1` 则提高 22.065 点。整组保留 SOF 有收益，`DJI_0109_1` 提供了检查局部退化的案例。

完整几何诊断覆盖校准的 2,750 个连续帧对及评估的 9,810 个连续帧对。评估段估计平移的中位数为 0.194 像素，P90 为 1.662 像素。`DJI_0109_1` 平移 P90 为 4.960 像素，`DJI_0277_2` 达到 13.036 像素且开启补偿明显受益。因此单凭平移量无法决定是否回退。光流和重投影值来自独立的 SOF 风格诊断，用于定位帧级案例。各帧的几何量和同帧 CLEAR 得失随完整实验包保存。

## M3 · 检测覆盖与 RGB 特征

- 9 个校准段使用原始 RGBT 检测和配套 RGB 特征，9 段哈希与索引均通过。30,165 个高分检测有有效 RGB 特征，21,530 个低分检测无特征。
- 已标注身份且符合时间与中心距离约束的 24,643 个同 ID 对、34,676 个异 ID 对，余弦距离中位数为 0.351 和 0.907，离线排序 AUC 为 0.987。在 <8 像素的样本中 AUC 为 0.970。按现有 0.4 距离参考线，同 ID 对通过比例为 61.1%，隔 1–3 帧降为 32.3%，隔 11–30 帧为 14.0%。长间隔同 ID 样本只有 229 对，且所有统计以有有效特征的样本为条件。
- 使用归档 RGB ReID 主基线做缺口诊断。39,992 个未匹配真值帧中，33,728 个（84.3%）没有 IoU ≥0.5 的检测候选，4,004 个只有低分候选。诊断匹配与 TrackEval 采用各自定义。补齐低分身份信号前，当前 RGB 结果可以支持高分候选的局部身份比较，低分恢复仍缺少对应特征证据。
- 21 段评估里另为 M2 四组生成了各自的覆盖、缺口和诊断身份变化。分层汇总表随本报告提供，逐帧记录保存在完整实验包。
