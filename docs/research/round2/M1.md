# M1：逐步验证相机运动补偿的可靠性

本批次把 M1 实现为独立 CMC 对象，由实验运行器注入原生 `native_iou` 跟踪器。检测缓存、关联规则、卡尔曼更新与轨迹生命周期沿用基线。实现位于 `botsort_research/robust_cmc.py`，原生 BoxMOT SOF 不做修改。

第一批实验中，整体关闭 CMC 降低了 HOTA 与 IDF1，同时少数序列在关闭后明显改善；因此要验证的是“哪些估计应接受、简化或拒绝”，不能把 CMC 整体关闭当成改进。原始证据见 [第一批结果](../results/round1_2026-11-25/README.md) 和 [各序列指标](../results/round1_2026-11-25/sequence_metrics.csv)。

## 1. 六组对照回答六个问题

| CMC 参数 | 实验内容 | 要回答的问题 |
|---|---|---|
| `none` | 单位变换 | 完全不补偿时损失多少？ |
| `sof` | 原生 SOF | 第一批阳性对照能否复现？ |
| `m1_native_scale` | 原生像素坐标拟合、3 px RANSAC 阈值 | 缩小坐标中的宽松阈值是否带来错误补偿？ |
| `m1_mask_grid` | 上一项 + 前景遮罩 + 网格均衡选点 | 运动目标或局部纹理集中是否主导变换？ |
| `m1_fb` | 上一项 + 前后向光流一致性过滤 | 不可靠的点对应是否是主要误差来源？ |
| `m1_reliable` | 上一项 + 留出点验证 + 模型回退 | 有证据地拒绝或简化估计能否改善跟踪？ |

六组首先全部搭配 `native_iou` 与原生 KF，单独评估 M1。M2、M3 的联合作用留给独立模块有明确收益之后。本文件中的默认值是待验证的起点，不是已经通过数据验证的最优值。

`m1_native_scale` 还包含基本边界、有限值和原始图像尺寸检查；它不是对原生 SOF 的逐字节复制。真正的原生对照始终是 `sof`。

## 2. 每帧如何处理

每次 `apply(image, detections)` 只读取上一帧保存的图像/角点、本帧图像及本帧检测。返回从上一帧到当前帧的 2×3 变换，用于原生 `STrack.multi_gmc`。第一帧只有初始化；没有跨越未来帧或 GT 的路径。

**坐标统一。** LK 在缩小图像上运行，拟合前把点恢复到原生坐标。实际缩放率分别使用 `small_width / native_width` 与 `small_height / native_height`，并遵循像素中心约定：`native = (scaled + 0.5) / scale - 0.5`。随后在原生坐标直接估计平移、旋转和均匀缩放的部分仿射，因此 RANSAC 的 3 px、FB 的 2 px 都表示原图像素。没有用名义 `0.15` 直接替代取整后的实际比例。

**遮罩和网格。** 从 `m1_mask_grid` 开始，把分数严格大于 0.1 的检测框向外扩展 3 原生像素后遮罩。上一帧选点时使用上一帧检测，本帧跟踪终点再次检查本帧遮罩。4×4 网格各自限额，空网格的名额不向其他网格转移；空间覆盖不足会真实地保留在诊断中。检测遮罩只是一种前景抑制假设，不能覆盖未检出的目标或把海浪自动变成静态背景。

**FB 过滤。** 从 `m1_fb` 开始，将本帧点反向跟踪到上一帧；正反向状态有效且往返误差不超过 2 原生像素才保留。其作用是删除不一致对应，不能证明剩余对应来自真实静态背景。

**可靠性与回退。** `m1_reliable` 固定留出对应列表中每五个点的第一个用于验证，成员选择不依赖残差或 GT。留出点不参与拟合、RANSAC 或后续重新拟合。先检验部分仿射；若不可靠，再用拟合点位移中位数拟合平移模型，并独立检验；两者都不通过才返回带有失败标记的单位变换。

检验包含内点数量、内点比例、4×4 网格覆盖、内点空间分布条件数、缩放范围，以及留出点残差和留出点内点比例。平移回退还检查各个有支持网格的位移中位数是否一致。**没有按平移幅度直接拒绝相机运动的规则**：真实大幅相机移动仍有机会通过对应证据获得支持。

单位变换回退意味着“本帧没有获得可信估计”，不意味着“测得相机静止”。当前版本沿用原生 GMC 对状态及协方差的处理，尚未把 CMC 参数估计不确定性额外传播到 KF。

## 3. 默认参数与运行

| 参数 | 默认值 | 含义 |
|---|---:|---|
| `scale` | 0.15 | 光流图像缩小比例 |
| `ransac_native_px` | 3.0 | 原生坐标 RANSAC 内点阈值 |
| `max_corners` / `grid` | 1000 / 4 | 总角点上限与 4×4 网格 |
| `mask_score_threshold` | 0.1 | 遮罩使用分数严格大于此值的检测 |
| `mask_margin_native_px` | 3.0 | 前景框外扩像素 |
| `fb_native_px` | 2.0 | 最大往返误差 |
| `min_reliable_points` | 8 | 最少拟合内点 |
| `min_holdout_points` | 4 | 最少留出对应 |
| `min_inlier_fraction` | 0.5 | 拟合与留出对应的最低内点比例 |
| `min_grid_coverage` | 0.25 | 内点至少覆盖四个网格 |
| `max_spatial_condition` | 100 | 避免近共线、单方向分布的支持 |
| `min_affine_scale` / `max_affine_scale` | 0.8 / 1.25 | 部分仿射缩放范围 |
| `max_holdout_median_native_px` | 3.0 | 留出点残差中位数阈值 |
| `max_translation_disagreement_native_px` | 3.0 | 平移回退的网格位移分歧阈值 |

批次运行使用本目录总说明中的统一命令。单独重放一个实验的例子：

```bash
python -m botsort_research.cli run \
  --image-root "$VT_IMAGE_ROOT" \
  --split configs/research/split_retrospective.json \
  --subset evaluation \
  --variants native_iou \
  --cmc m1_reliable \
  --trace \
  --output outputs/round2/m1_reliable
```

每次使用新的输出目录；不要覆盖已完成实验。配置、运行环境、输入指纹及各模式的实际参数写入实验记录。参数探索先在 9 条 calibration 序列上完成，并保留选择记录；21 条 evaluation 序列仍属于回顾性开发比较，不能重新称作未使用的最终测试集。

## 4. 返回哪些证据

开启 `--trace` 后每帧都有 `stage="cmc"` 事件，包括初始化和失败。重点保留：

- `status`、`estimated`、`model`、`reasons`、两个候选模型的拒绝原因和最终 `warp`。
- 初始角点数、正向有效数、遮罩后数量、FB 后数量与 FB 残差分位数。
- 拟合/留出点数量、内点比例、网格覆盖、空间条件数、拟合与留出残差。
- 仿射缩放、旋转、平移幅度，以及平移回退的网格位移分歧。

解释顺序建议为：先比较 TrackEval 的 HOTA、IDF1、FP、FN、IDSW；再按序列/目标尺度检查变化；最后定位身份变化或漏检附近的 CMC 事件和原始图像。单独看到低残差或高内点比例，不能得出相机运动估计准确的结论。

尤其检查以下失败模式：掩膜使可用背景过少、低分辨率 LK 窗口受移动前景影响、重复纹理产生一致但错误的位移、有效运动在可靠性门控中被过度拒绝。合成运动测试中，大幅移动前景在较粗尺度上仍可能污染掩膜外的光流；此时可靠性检查可以选择回退，但真实数据是否因此获益必须由跟踪结果验证。

## 5. 验证范围与依据

`tests/test_robust_cmc.py` 验证已知平移、旋转、缩放、尺寸取整后的坐标恢复、移动前景遮罩、留出对应与拟合对应冲突、共线支持、平移回退、空纹理与图像尺寸变化。命令：

```bash
python -m unittest tests.test_robust_cmc -v
```

这些测试验证实现和失败语义。真实数据上的精度、回退频率与时间开销，需要完成本批次实验后填写。

实现参考：原生 [BoxMOT v16.0.11 SOF](https://github.com/mikel-brostrom/boxmot/blob/v16.0.11/boxmot/motion/cmc/sof.py)；OpenCV 的 [部分仿射/RANSAC 接口](https://docs.opencv.org/4.13.0/d9/d0c/group__calib3d.html) 和 [稀疏金字塔 LK 接口](https://docs.opencv.org/4.13.0/dc/d6b/group__video__track.html)。具体运行版本仍以本仓库实验清单记录的原始环境为准。
