# M2：面向微小目标的概率几何关联最小原型

## 实验要回答的问题

微小目标的框偏移少数像素就可能造成 IoU 明显下降。该分支检验：在固定检测缓存、相机运动补偿和轨迹生命周期的条件下，使用运动预测不确定性与检测测量噪声的概率关联，能否减少关联中断。代码是可运行研究原型；默认参数尚未通过数据实验验证，不能把功能完成写成指标提升。

第一轮使用 `botsort_no_reid` 作为直接对照。冻结的 `botsort_reid` 结果可作参考，但不能将“去掉 ReID 后改变关联”全部归因于 M2。ReID 余弦距离与高斯负对数似然不同量纲，本轮不直接取二者最小值或相加。

## 数学定义与代码对应

状态为 `x=(cx, cy, w, h, vx, vy, vw, vh)`，测量为 `z=(cx, cy, w, h)`。沿用 BoxMOT 的预测、过程噪声 Q 与 SOF 相机运动补偿，获得当前帧的预测均值和协方差。

对轨迹 i 和检测 j：

```
r_ij = z_j - H x_i
S_ij = H P_i H^T + R_ij
C_ij = 0.5 * (r_ij^T S_ij^-1 r_ij + log(det(S_ij)) + 4 log(2 pi))
```

坐标统一为原始图像像素；密度参照单位固定为每维 1 像素。常数项保留，因此拒配代价必须按该定义配置。`logdet` 项惩罚过大的不确定性体积，避免单独使用马氏距离时协方差很大的丢失轨迹占据候选。高斯假设本身仍是近似。

`botsort_research/association.py` 计算代价，并以四维马氏距离、绝对中心距离和宽高比变化进行门控。运行配置 `configs/research/m2_default.json` 中，第一阶段使用马氏距离上界 18.4668（四维卡方分布 0.999 分位数）、64 像素中心上限、4 倍尺寸上限及 `miss=unassigned=8`；第二阶段分别为 13.2767（0.99 分位数）、32 像素、3 倍和 `miss=unassigned=6`。这些均是起始假设，不保证真实误差满足卡方分布，须在独立开发数据上校准；第二阶段设置较严格并不意味着已证明最优。

`NoiseModel` 的自适应测量方差为：

```
R_j[k,k] = floor_std[k]^2
           + (size_scale[k] * [w_j,h_j,w_j,h_j][k])^2
           + score_scale[k]^2 * (1 - score_j)^2
```

参数名中 `std/scale` 是标准差系数；离线非负回归拟合方差系数后须开平方再导出。每一对候选使用的 R 会保留并用于该对成功匹配后的 Kalman 更新，而不是在更新时另用默认 R。自适应更新采用 Joseph 形式保持数值对称性与半正定性。检测初始化 P0、运动模型、过程噪声 Q 不变。相机运动不确定性不重复放入 R。

基线 R 消融采用 BoxMOT 原来的 `diag((0.05*[pred_w,pred_h,pred_w,pred_h])^2)`。虽然底层 KF 接口支持 confidence 参数，v16.0.11 的 STrack 更新没有传入它，因此该消融不能擅自乘 `(1-score)`。该消融保留原生 Kalman 更新；自适应 R 两组才更换更新实现。

## 显式拒配

目标函数同时包括匹配代价、每条未匹配轨迹的 miss 代价和每个未分配检测的 unassigned 代价：

```
min sum(C_ij * X_ij) + sum(miss_i * u_i) + sum(unassigned_j * v_j)
subject to sum_j X_ij + u_i = 1
           sum_i X_ij + v_j = 1
```

增广 Hungarian 矩阵为每个轨迹和检测设置独立虚拟节点，即使所有真实候选被门控也可求解。`C_ij >= miss_i + unassigned_j` 时提前拒绝，等价最优解中的价格相等情形选择拒配。不使用 BoT-SORT 的 0.8 IoU 距离阈值切 NLL。

## 四组代码开关

| variant | 关联 | 测量更新 | 用途 |
|---|---|---|---|
| `native_iou` | 原生全部流程 | 原生 | 直接数值回归与基线对照 |
| `m2_nll_baseline_r` | 高分/低分阶段 NLL | 原生 R、原生更新 | 分离概率关联本身的效果 |
| `m2_nll_floor` | 高分/低分阶段 NLL | 人工起始像素噪声下限、尺寸/分数项 | 验证小目标噪声下限假设 |
| `m2_nll_calibrated` | 高分/低分阶段 NLL | 从开发校准序列拟合的 R | 验证校准是否优于手工设置 |

第一阶段仍允许活动和丢失轨迹参与；第二阶段仍仅使用尚未匹配的活动轨迹。未确认轨迹的关联保持原生的 score-fused IoU 与 0.7 阈值；自适应两组对其测量更新仍采用同一检测噪声模型。丢失轨迹不能由低分检测恢复；低分检测不能创建新轨迹；不做轨迹插值或回填输出。15 FPS 与 `track_buffer=60` 仍对应 30 个丢失帧。

## 软件边界与验证

适配器只依赖已经审阅的 BoxMOT v16.0.11 四个核心源码文件，并验证源码哈希和私有方法签名。该 tag 的 `boxmot.__version__` 残留为 16.0.10，因此仅检查版本字符串不可靠；运行清单同时记录分发版本、包版本与实际加载源码。版本变化需重新审阅，不能直接关闭检查。

纯数值测试覆盖噪声公式、原生 R、Joseph 更新、空输入、全拒配、负 NLL、全局最优赋值与穷举一致性、无重叠微小框可匹配、宽协方差惩罚、物理门控和非法参数。设置 `M2_TEST_BOXMOT=1` 后，另外验证原生工厂与直接 BotSort 输出完全相同，以及低分更新、短时丢失、高分恢复、阈值边界、未确认轨迹与缓冲期等真实运行时行为。合成测试通过不代表真实场景指标提升。

离线校准和诊断允许读取 GT；跟踪运行只接收图像、冻结检测和拟合后的噪声参数，禁止读取 GT。旧 official test 已参与历史选择，应标为回顾性开发实验。新的干净留出集才能支撑独立泛化结论。

## 第一轮之后再做的工作

先比较每组总体 HOTA/AssA/IDF1、FP/FN/IDSW，再分尺寸、间断长度和分数段检查收益及误配。必要时加入只放宽原生阈值的控制组与中心距离/NWD 控制组，排除收益仅来自放宽门控。当前未实现“低分创建轨迹”“延长 buffer”“外观融合”和 M1 不确定性传播；这些改变需分别做受控消融。概率关联、测量噪声校准和噪声下限都已有相关研究，不能仅凭模块命名主张原创性，论文需结合特定场景机制、实验和已有工作进一步界定贡献。
