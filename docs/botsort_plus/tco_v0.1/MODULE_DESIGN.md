# TCO v0.1：轨迹条件化时序观测增强设计

日期：2026-11-27。设计基座：235fe4097066b5023cc84ca8cd6edd5757fd658c。拟工作分支：research/vttiny-track-conditioned-observation。

**本文件是待本地实现和验证的模块规范。文中的网络、损失、触发条件和训练预算均为设计，不是已经完成的训练、真实数据结果或性能承诺。** 现有 B、GMC、③④⑤及神经 Q/R 的真实结论引用末尾的固定版本材料。阶段执行、进入条件与停止条件以 [EXPERIMENT_PLAN.md](EXPERIMENT_PLAN.md) 为准。

## 1. 研究问题与首版范围

TCO 是 Track-Conditioned Observation 的缩写。本研究检验：对已经确认身份、进入原生低分关联阶段的轨迹，能否利用当前图像和近期真实观测中的目标信息，得到比原始低分检测更准确的测量框，并把局部改善转化为持续正确覆盖。

首版研究对象是已经存在的真实检测行。TCO 不直接学习 Q/R，不把相机预测框当作新测量，也不改用低分框创建新 ID。它首先估计“当前候选能否支持这条轨迹”及“修正后的框是否比原框更好”，再在限定的原生低分阶段使用修正结果。

| 内容 | v0.1 决定 |
|---|---|
| 图像 | RGB；热红外作为后续独立扩展 |
| 候选检测 | 原生低分分支实际保留的检测行，保留原始 det_index、score、class |
| 轨迹 | 原生高分关联后仍未匹配、且处于 Tracked 的已确认轨迹 |
| 首个闭环模式 | fixed_pair_refine：先执行该运行自己的原生低分匹配，再只细化已匹配对的测量框 |
| 条件后续模式 | low_stage_pair_refine：在同一低分节点与原几何可行边中，使用成对细化框重新计算原 IoU 代价 |
| 保持原算法的部分 | 高分、Unconfirmed、原生出生、B 的候选历史与 Lost 恢复规则、KF 方程与参数 |
| 首版关闭 | 新候选生成、低于原可用分数区间的准入、扩关联范围、强负例否决、高分测量细化、RGB-T、A/A2、C2、预测输出 |

“保持原算法”表示算法及参数保持，不表示闭环轨迹与参考永远相同。一次真实测量变化可以影响下一帧的状态、高分分配、Lost 状态和 B 恢复；这些传播必须记录与评估。

### 1.1 为什么从这一范围开始

已有 D3 中，210 次正确恢复后首次中断有 188 次当帧无可用检测：95 次定位未达到同目标 IoU 0.5，89 次分数不可用，4 次无检测行。[R3]

这组证据提供方向，不能作为 v0.1 的可解决数量。首版 fixed_pair_refine 只作用于已匹配的低分测量；原阈值外或完全无框的事件不在它的覆盖范围。low_stage_pair_refine 也不扩大原可行边。T1 必须分别计算各模式的实际可达错误。如果只有少量已知案例符合资格，停止首版闭环投入，重新登记独立扩展，不能把范围在实验中悄悄放宽。

神经 R 使用的是分数、尺寸、重叠及 RGB/IR 对比度、标准差、梯度等代理量，其失败不等于直接学习空间图像信息已经失败。[R2] 但旧 RGB/IR 模板平移的增量很小，因此本模块需要与手工空间相关方法进行对照。[R6]

## 2. 在现有代码中的位置

基座的 botsort_plus/adapter_v2.py 已有明确次序：[R7]

1. 分离高低分检测，执行 KF 预测与 GMC。
2. 原生高分关联。
3. 从未匹配池中选择仍为 Tracked 的 low_tracks。
4. 构造 low_detections，计算 IoU 代价；如配置了 guard_low_cost，执行原保护。
5. 低分 Hungarian，随后对接受配对调用 track.update。
6. Unconfirmed 关联、残余候选池、B 的 Lost 身份恢复。
7. 原生出生与最终输出。

TCO 的首个实现点是第 5 步“匹配已确定、更新尚未发生”的边界。T3b 的实现点才前移到第 4 步。两种模式必须分别命名、分别运行，不能混合汇报。

~~~mermaid
flowchart TD
    A["KF、GMC与原生高分关联"] --> B["原生低分节点与保护规则"]
    B --> C["原生低分匹配"]
    C --> D{"TCO修正证据充分？"}
    H["帧前历史与当前RGB局部区域"] --> D
    D -->|是| E["使用成对细化测量框"]
    D -->|否| F["使用原始测量框"]
    E --> G["原生KF更新"]
    F --> G
    G --> I["Unconfirmed、残余候选与B恢复"]
~~~

该图只描述 fixed_pair_refine。低分匹配没有被影子历史预先固定；每一帧都使用该变体自身已有状态计算原始低分关联。不能把历史参考运行未来已经知道的配对抄过来，再称为闭环实验。

## 3. 观测、历史与坐标约定

### 3.1 主键与来源

每个候选的不可变主键为：

~~~text
(sequence, frame, track_id, det_index)
~~~

其中 frame 沿用实际跟踪帧号；det_index 是进入该帧跟踪器的原始检测行索引。它不是按分数或最近框事后猜出的索引。

同时保留：

- raw_xyxy：未改动的原始检测框；
- pred_xyxy：当帧 KF/GMC 后、测量更新前的轨迹框；
- refined_xyxy：本对候选的 TCO 细化框；
- raw_score、raw_class、source_detection_sha；
- history_observation_keys 及其帧号；
- source_image_sha、image_shape、ROI 与逆变换参数；
- encoder/model/config 的摘要。

训练、离线诊断和在线决策使用分开的记录。GT 身份、IoU 标签、未来 5/10 帧结果和可达性判断只放在离线标签侧。

### 3.2 近期历史缓冲

设计默认：

| 参数 | 值 |
|---|---:|
| 最大历史观测数 | 3 |
| 最大观测年龄 | 12 帧 |
| 使用 TCO 所需最少历史观测数 | 2 |
| 历史可用时间 | 至多 t−1 |

历史记录来自实际已接受、具有原始检测行和实际图像像素的观测。高分、低分或 B 恢复的实测观测可以被记录；预测输出、伪框以及单纯的 KF/GMC 结果不能写入图像历史。

每一帧开始时冻结历史快照，所有 TCO 配对共用该快照。帧末才追加本帧实际接受的原始检测观测。即使状态更新使用了 refined_xyxy，历史的提名来源仍保留 raw_xyxy，避免反馈中把模型的偏移当成新的独立图像证据。

历史沿实际轨迹 ID 维护，结束或移除后清理。B 使用旧 ID 恢复后可以继续保留年龄仍合法的真实历史；超过年龄的条目不得复活。历史不足时沿用原始测量，并记录 fallback 原因。

首版不追加 C2 式外观写入门控。训练与诊断中应保留真实跟踪产生的历史污染现象；无法可靠确定历史身份的标签保持未知，不假定每条历史都是干净的。

### 3.3 ROI 生成

RGB 输入通道顺序在适配层显式转换并校验。像素采用固定归一化，RGB/255 后映射到 [−1,1]；不使用测试视频统计重估均值或方差。

当前 ROI 以 raw_xyxy 中心为中心，各轴请求范围为原宽高的 2.5 倍，且不小于 24 原图像素。历史 ROI 使用各自真实框中心、原宽高的 1.5 倍，各轴不小于 12 原图像素。任一请求轴超过 128 像素时，首版回退；不能为了符合上限把目标悄悄裁掉。

当前 ROI 等比例缩放并 letterbox 到 96×96，历史 ROI 到 64×64。图像边界外区域填充，同时提供有效像素 mask。请求 ROI、与图像相交的有效区域、缩放系数和 padding 必须完整保存。

输入为五通道：

1. RGB 三通道；
2. valid_mask：真实图像像素覆盖区域；
3. proposal_mask：原始候选框在该 ROI 内的位置。

proposal_mask 只能使用原始检测或历史实测框，不包含 GT。当前 ROI 的空间范围来自当前候选，不利用 GT 中心移动搜索区。valid fraction 小于 0.5、框无效或请求范围超限时均回退。

坐标采用原图连续 xyxy、右下边界不含端点的统一约定；bbox 边界通过仿射尺度与 padding 变换，像素采样采用明确的像素中心约定。必须分别验证单像素中心和框边界，不能混用 align_corners 的映射。GT 不因 ROI 或模型输出而裁剪。图像边界附近的遮挡与截断作为分层报告。

## 4. 最小网络：tco_small_conv_v1

### 4.1 为什么选择明确的小型 RGB 网络

首版采用一个共享的小 CNN，而不假定现有 RGB ReID 的全局向量具有定位所需的空间信息。网络需要本地训练，随机初始化的输出不具备使用资格。

既有 ReID 的 pre-pooling 特征可以作为后续编码器替换对照，但必须先确认真实模块路径、空间步长、归一化和权重摘要。不得把插值后的特征尺寸当作新增分辨率，或把预训练编码器的额外收益归到时序机制。

### 4.2 张量与层结构

~~~text
current:   [N, 5, 96, 96]
history:   [N, 3, 5, 64, 64]
hist_valid:[N, 3]
hist_dt:   [N, 3]
geometry:  [N, 8]
~~~

8 项几何元数据固定为：raw_score、log(w/image_width)、log(h/image_height)、预测相对原框中心的 dx/w 与 dy/h、log(pred_w/w)、log(pred_h/h)、最近历史年龄除以 12。宽高均须先通过正值检查。所有对照共用这些信息，不把它们声称为图像贡献。

共享编码器 E：

| 层 | 通道 | 核／步长 | 归一化与激活 |
|---|---|---|---|
| Conv1 | 5→32 | 3×3／2，padding 1 | GroupNorm(8)，SiLU |
| Conv2 | 32→64 | 3×3／2，padding 1 | GroupNorm(8)，SiLU |
| Conv3 | 64→64 | 3×3／1，padding 1 | GroupNorm(8)，SiLU |
| Conv4 | 64→64 | 3×3／1，padding 1 | GroupNorm(8)，SiLU |

当前输出为 [N,64,24,24]，单个历史输出为 [N,64,16,16]。编码器权重在两路共享。所有池化与注意力使用有效区域 mask，padding 不能成为目标线索。

对第 k 个历史，从 proposal_mask 覆盖区域和周围上下文分别做带 mask 的池化，拼接时间间隔编码，得到历史 token h_k。历史 token 经过一个小型注意力聚合器得到轨迹 query h_i；attention 的无效历史项被 mask。不得在所有历史均无效时直接执行全负无穷 softmax。

为使本地实现具有唯一的首版规格，聚合与融合采用以下尺寸：

1. 历史 token：目标 mask 内平均特征 64 维、有效上下文环平均特征 64 维、时间编码 8 维，合计 136 维；经 Linear(136,64)、SiLU、Linear(64,64)。时间编码使用归一化年龄的一层 Linear(1,8) 与 SiLU；没有上下文环时以零向量和记录标志处理，不能除以零。
2. 当前 proposal 的目标／上下文池化也经过同一 token 投影器，时间编码取 0，得到当前 query。Q/K/V 均为 64→64 的线性映射，单头注意力的缩放为 sqrt(64)；历史无效项被 mask，聚合得到 64 维历史表示 h_i。
3. 当前空间特征与 h_i 计算逐位置归一化点积响应。拼接当前特征 64 通道、广播历史表示 64 通道、响应图 1 通道、proposal mask 1 通道、valid mask 1 通道和相对原 proposal 中心的 x/w、y/h 坐标图 2 通道，共 133 通道。坐标由 ROI 的原图逆变换计算，padding 部分置零并使用 valid mask 区分。融合为 Conv1×1(133,64)、GroupNorm(8)、SiLU、Conv3×3(64,64,padding=1)、GroupNorm(8)、SiLU，得到 Z，尺寸仍为 [N,64,24,24]。坐标通道为回归保留位移方向，不能依赖全局平均池化自行恢复绝对位置。
4. 对 Z 的有效区域平均池化 64 维、proposal 区域平均池化 64 维、h_i 64 维，加 8 项几何元数据，构成 200 维向量。support 头为 Linear(200,64)、SiLU、Linear(64,1)；box 头为 Linear(200,128)、SiLU、Linear(128,4)。
5. 共享质量头对指定框从 Z 采样 3×3 区域特征，展平为 576 维，加 h_i 的 64 维及该框在 ROI 中归一化的 xyxy 4 维，共 644 维。两次调用同一 Linear(644,128)、SiLU、Linear(128,1)，分别产生原框与细化框质量。区域采样必须遵守上节同一坐标约定。

mask 下采样采用覆盖比例，目标／上下文池化以比例作权重。分母为零时记录缺失并按确定规则回退。当前局部区域保留空间格点，不能在定位前完全压成一个全局余弦分数。上述宽度和层数是初始设计；任何改变均递增模型版本并重新比较容量控制。

### 4.3 三类输出头

**目标支持头：** 输出 v_i，表示当前候选对于该轨迹的支持分数。训练后仍需在实际候选分布上检查可靠性；sigmoid 数值不自动等于校准后的概率。

**框细化头：** 输出四个残差参数 a_x、a_y、a_w、a_h。令原框中心、宽高为 (c_x,c_y,w,h)，使用：

$$
\begin{aligned}
\Delta x &= \min(3,\ 0.25w)\tanh(a_x),\\
\Delta y &= \min(3,\ 0.25h)\tanh(a_y),\\
w' &= w\exp\!\left(\log(1.25)\tanh(a_w)\right),\\
h' &= h\exp\!\left(\log(1.25)\tanh(a_h)\right),\\
c_x' &= c_x+\Delta x,\qquad c_y'=c_y+\Delta y .
\end{aligned}
$$

中心位移最多为各轴原尺寸的 25%，并受 3 像素上限约束；宽高倍率在 [0.8,1.25]。这些是预先规定的首版设计范围，尚未证明为最优参数。

**共享定位质量头：** 同一个评估器分别读取原框和细化框在当前空间特征上的区域表示，输出 q_raw 与 q_ref。q_ref 的取样坐标在质量损失回传时 detach，避免质量头通过移动框来人为抬高自己的标签。目标是身份条件定位质量：明确同身份正例使用各自与正确身份 GT 框的 IoU，明确负例为 0，未知例忽略。不能用对任意 GT 的最大 IoU 代替这一监督。

输出契约：

~~~text
support_score: float
quality_raw: float
quality_refined: float
box_delta: float[4]
refined_xyxy: float[4]
eligible: bool
fallback_reason: str | null
history_observation_keys: list
model_sha256: str
~~~

原有 score/class/det_index 均不被这几个模型分数覆盖。

support 与两个质量标量在各自最后一层后使用 sigmoid；框头输出未经 sigmoid 的四个实数，再经上述 tanh 残差参数化。共享质量头的两次调用共用全部权重。

### 4.4 修正应用条件

实际应用同时要求：

- 历史、像素、坐标与候选资格检查全部通过；
- v_i ≥ τ_support；
- q_ref ≥ τ_quality；
- q_ref − q_raw ≥ τ_gain；
- refined_xyxy 合法，位移与尺寸位于设计域内；
- 占用、保护与原可行边约束通过。

三个阈值在训练来源的 calibration 母视频上选择，连同选择准则、数据摘要、权重摘要一起冻结。设计协议中初始值应为 null，不能直接拿官方开发测试视频挑阈值。

证据不够时使用原框／原代价，记录回退原因。v0.1 的“验证”首先用于决定是否接受一次修正，不能默认据此删除原检测、拒绝原本合法的匹配或冻结 B 的记忆。强负例否决属于单独扩展，必须独立消融。

## 5. 标签、损失与训练样本

### 5.1 训练样本必须来自真实候选分布

训练来源使用官方训练序列，按母视频划分 fit、calibration 与 holdout，并排除与当前开发测试集共享母视频的片段。建议比例为 70%／15%／15%，实际母视频列表与必要偏差在 T1 导出样本前冻结。

先运行冻结跟踪器生成真实状态、检测索引和匹配机会，再构造样本。不能仅用 GT 裁块之间的容易正负对训练，然后用这些结果代替线上难例证据。

按以下层分别保留样本和分母：

1. 正确低分测量，原框已经较准；
2. 正确身份但原框偏移／尺度不准；
3. 同类邻近目标形成的身份竞争；
4. 有明确依据的背景候选或目标已经离开；
5. 身份、标注完整性或对应关系不确定。

第五类不作为背景负例。已有 E3 的未匹配 GT 轨迹不能整体赋负标签；22 例人审只能验证对应样例，不得直接向整条轨迹传播。[R5]

### 5.2 身份与定位标签

历史身份锚点由离线 GT 配对确定，匹配规则与歧义处理写入标签协议。至少两个近期可核对观测指向同一已知 GT，且其他已知历史不与之冲突时，才可为对应轨迹构造明确身份监督。未知或混杂历史单列，不能在推理端仿照 GT 清洗。

当前候选与该身份对应且可确定时，support 标签为正；唯一对应另一个身份，或经可靠标注确认当前无该目标时，才是负。附近同时包含多个可能目标而不能排歧时忽略该监督项。

回归目标是正确身份在当前帧的原始 GT 框。GT 框不裁剪到搜索 ROI，也不先缩到模型可行域来制造“更准确”的标签。真实目标超出残差可行域时应记录为不可完全到达，仍用真实 IoU 评估输出。

q_raw 和 q_ref 使用同一身份条件质量定义：正例分别取原框、细化框对同一目标 GT 的 IoU；q_ref 的标签由当前前向框计算后 stop-gradient。身份明确负例质量目标为零；未知样本不参与有监督质量损失。

### 5.3 损失

初始损失设计为：

$$
L=L_{\mathrm{support}}
 +2L_{\mathrm{box}}
 +L_{\mathrm{GIoU}}
 +0.5\left(L_{q,\mathrm{raw}}+L_{q,\mathrm{ref}}\right).
$$

- support 使用带样本权重的 BCE；
- box 使用按原框宽高归一化的中心与对数尺寸 Smooth L1，只对身份明确正例回传；
- GIoU 同样只对身份明确正例；
- 两项 q 使用 Smooth L1，标签取真实 IoU；
- 首版不加入 NLL、Q/R 学习、全局新类别分类或新的 ReID 损失。

负样本以真实同帧近邻为主，限制同一长轨迹在一个 minibatch 中重复主导。采样可以提高困难负例比例，但 calibration 和 holdout 统计必须恢复真实候选分布；不能把人为平衡后的命中率直接叫部署精度。

### 5.4 初始训练预算

| 设置 | 设计默认 |
|---|---|
| 优化器 | AdamW |
| 学习率 | 3e−4 |
| weight decay | 1e−4 |
| batch size | 64；显存不足时以梯度累积保持有效 batch |
| 最大 epochs | 20 |
| 最大优化步数 | 20,000；与 epochs 上限取先到者 |
| 最早早停 epoch | 2 |
| calibration 早停 patience | 4 次 epoch 评估 |
| pilot seed | 41 |
| 方案冻结后重复种子 | 41、42、43 |

早停主指标和权重选择规则应在首次训练前登记，不能用 holdout 或官方 30 段选 checkpoint。采用“在冻结正确观测损伤预算内的净正确框收益”，同时报告 support 与定位质量。T1 根据真实队列登记损伤预算、分母和指标计算，再开始首次训练；若无法稳定定义该指标，必须先补充 protocol，而不能临时改用看起来最好的一项 loss。

## 6. 三种模式的精确定义

### 6.1 固定候选／固定配对的离线模式

从封存运行导出候选和帧前历史，比较原框、当前像素头、历史条件头。在同一候选上评估身份可判定性、IoU 变化和错误修正。

该模式没有未来闭环状态变化，不能产生正式 HOTA 改进结论。它用于判断网络是否有可用图像信息、是否优于手工模板，并筛掉没有局部收益的方案。

### 6.2 fixed_pair_refine：首个闭环

每帧步骤：

1. 使用该运行当前状态执行原生高分、低分代价、保护和 Hungarian；
2. 对实际接受的低分配对，从帧前历史与当前 RGB 取得 TCO 预测；
3. 通过修正条件时创建配对专属的 STrack 测量对象；raw score/class/det_index 不变；
4. 调用同一原生 track.update；失败时使用原测量；
5. 其余状态机继续运行。

原始 all_dets 数组不得被原地改写。B 的 Observation 仍由真实残余检测行构造，未消费检测的框、分数与特征不被先验修改。

为了隔离测量效果，首版 RGB ReID 缓存仍来自原始检测裁块，不因 TCO 细化框重新提取后写入原生或 B 外观库。这是一次控制变量选择，需要在局限中披露；如以后要同步更新特征，必须作为新因子消融。

已接受低分配对的身份和数量在该帧的 TCO 介入前已经确定，但后续帧可以变化。旧 guard 拒绝的配对不进入本阶段。

### 6.3 low_stage_pair_refine：条件推进

只有 fixed_pair_refine 的测量改善在留出视频成立，且 T1 显示原可行边中仍有可纠正竞争，才进入此模式。

同一低分 track i 与 detection j 可产生各自不同的细化框 b'ij。原始 detection j 依然只有一个所有者，Hungarian 的列节点仍按原 det_index 去重。

先保存原始代价 C0 和原保护的允许矩阵 M0。M0 包含：

- 与原求解器相同边界语义的几何可行条件；
- 原 GMC/dual_low 显式拒绝条件；
- 所有原有硬约束。

仅对 M0 允许的边运行细化。修正通过时用同一预测框与 b'ij 的 IoU 生成候选代价；修正不通过时使用 C0。最终求解阈值仍沿用原实现。M0 为 false 的边保持不可行，不能因位移、质量分数或更低代价复活。

原 guard 目前可能通过原地修改矩阵工作。实现时必须把“原始矩阵、保护后矩阵、允许标记”分开记录；无法明确还原拒绝原因的组合先标记为不可用，不能静默绕过保护。边界相等、NaN、空矩阵和重复检测要有专门一致性检查。

匹配完成后，仅对被选中的 (i,j) 使用其专属框进行更新；未匹配节点以原始检测继续进入残余候选池。TCO 不在此处生成新的 Lost 恢复路径。

一个更接近 GT 的观测可能离错误的 KF 先验更远，因此其 IoU 关联代价未必更好。这正是 T3a 与 T3b 必须分开验证的原因；不能把坐标改善自动解释为关联改善。

## 7. 对照组与机制归因

### 7.1 当前像素对照

当前像素对照与历史条件头使用相同编码器、头部、训练样本、优化预算、随机种子和标量几何信息。为控制分支容量，首版固定将历史像素槽填为当前 proposal 的同一裁块：在当前图像上按历史 ROI 规格（1.5 倍上下文、最小 12、最大 128、letterbox 到 64×64）构造，然后重复到合法历史槽。保留相同的有效槽 mask 与真实历史年龄元数据。它没有过去帧的外观信息，但仍运行相同结构。

这一替换方式必须在配置中明确登记为 current_repeat；三份当前裁块使用同一图像变换，不能让它通过额外独立增强获得不同训练预算。真正历史组登记为 causal_history。

两组应在同一可用历史事件集合上比较。历史不足导致的回退同时报告，不能只删除历史组的困难样本。

### 7.2 必要的反事实

在局部试验有效后，按计划增加以下定向对照：

- 历史打乱：固定已训练的 P3 模型，在不引入未来帧的条件下替换为其他轨迹的历史，检查模型是否实际利用身份；不是第五个训练臂；
- 关闭回归：保留同样预测与日志，使用原框；
- 仅原有分数／几何代理：与真正图像空间信息比较；
- 已有手工模板匹配：统一提名与位移预算，避免只因放宽范围获益。

打乱对照只用于诊断，不是部署策略。不同对照不得各自在官方开发测试集上搜索最优阈值。

### 7.3 与旧方案的关系

| 已有方案 | 已验证限制 | 本设计必须额外证明 |
|---|---|---|
| A/A2 | 弱观测起轨的误报代价 | 已有轨迹条件确实提供增量，不额外创建新 ID |
| C2 | 关联变化少，记忆冻结会伤害正确恢复 | 新空间表征提供增量，回退不冻结原有 B 库 |
| 原始 RGB/IR 模板 | 手工相似度／小平移增量有限 | 统一候选上学习式观测优于手工方法 |
| E2 | 固定补框坐标 TP 72→73，整体仍弱 | 作用于真实低分测量与状态，实际机会量足够 |
| ④／神经 R | 减弱好观测会造成后续漏跟 | 质量差值能识别值得修正的观测，闭环损伤受控 |
| B | 已有恢复收益与误报取舍 | 既改善 B 后续延续，也保留原有正确恢复 |

## 8. T1 的“上界”应如何解释

T1 至少报告原始候选可用性、历史资格、ROI 覆盖、残差范围和当前可见性，分别给出每类分母。

需要区分三种不同量：

1. **GT 精确可达性：** 正确 GT 的中心与尺寸参数是否位于预先给定可行域中。它不等于所有可跨过 IoU 0.5 的框数。
2. **GT 引导的可行修正：** 把 GT 残差投影到给定范围，或在有限网格内选择最好框。它是有用的诊断参照，但有限网格最优、简单 clamp 结果不是数学上的最大 IoU 上界。
3. **理想选择上界：** 在固定候选支持下允许离线 GT 做理想身份选择／定位，明确忽略真实图像是否可识别。它只能说明可能空间，不能当作新算法指标。

如果声称约束域内的严格 IoU 上界，必须说明求解器、界限误差与收敛证明；普通数值搜索应标为参考最优值。不能依据不可实现的 GT 结果宣称新模块具有预期收益。

## 9. 在线因果性、占用与复核要求

### 9.1 预测进程可见内容

只允许当前 RGB 图像、当前原检测、已发生的轨迹状态与过去真实观测。GT、人工标签、未来轨迹、未来图像及离线 oracle 不传入预测进程。

搜索 ROI、触发 eligibility 和 fallback 都必须在没有 GT 时可计算。标签生成进程与预测进程分离；候选主键与输入摘要用于后续联结。

### 9.2 容易混淆的约束

- 一个 det_index 最多消费一次，成对框不能被当作多个新检测；
- 对同一检测不同轨迹的预测必须来自同一帧前快照；
- TCO 不调用 activate/re_activate 分配 ID，已有 B 独占其恢复流程；
- 非选中配对不得写状态、历史或外观库；
- 原始检测数组、原 RGB ReID 缓存和原始 score 不被原地修改；
- 阈值、权重与训练划分在正式闭环前冻结；
- 原生输出裁剪行为继续原样，离线统计保留裁剪前后框；GT 不为迎合输出而裁剪。

### 9.3 需通过的实现复核

| 核验 | 通过条件 |
|---|---|
| 关闭 TCO | 相同环境、输入和配置下，MOT 与原有事件逐字节复现对应 B/BG 参考 |
| 只记录不应用 | 不改变 KF、ID、B 缓冲、外观记忆和正式事件 |
| 零残差／全部回退 | 精确复现原测量及基线轨迹 |
| 坐标往返 | 非方形框、边界 padding、1 像素位移和尺度变化均方向一致 |
| 历史截止 | 改动 t 之后的图像不能改变 t 的预测；t 当帧观测不得进入当帧历史 |
| 一对一 | 同检测两条边不能双消费，未选中边无写入 |
| 保护保持 | 原 guard 拒绝边在 low_stage_pair_refine 中不可复活 |
| 小目标／空输入 | 零检测、零历史、无效 ROI、极小框、部分越界均明确回退 |
| 模式区分 | 离线固定配对、闭环 fixed_pair_refine、闭环 low_stage_pair_refine 分别记录 |

软件一致性不等于真实收益。正式报告还要统计修正改变了多少真实决策、正确框被损伤多少、未来身份是否持续，以及收益集中在哪些母视频。

## 10. 扩展边界与论文表述

以下项目保留在设计后续，不在 v0.1 中默认开启：

1. 更宽的原低分候选边：必须重新定义机会集合、guard 对新边的判定和单独对照。
2. 原分数阈值外的已有框：必须保留原 detector score，说明新的准入规则，并重新核验 FP/FN 代价。
3. 无框时局部重检测：真正改变检测输入，须单列完整系统实验，不能混写成固定检测的关联改进。
4. RGB-T：先做当前真实难例的模态增量与局部错位验证，不能直接复制同坐标图块。
5. 强负例否决：需要可靠负标签与实际错误分布，不能用未匹配 GT 作为自动背景标签。
6. 新特征回写：若改变原生或 B 外观库，作为独立因子，避免重演 C2 的冻结反馈。

ReDet、时序特征和质量学习已有研究。潜在贡献应表述为：面向微小目标的轨迹条件观测建模、针对真实候选的定位质量差值应用，以及与既有 B/GMC 的可归因协同。只有实现、消融和留出证据支持的部分进入最终贡献陈述。暂不使用“首次提出”“已显著提升”等措辞。
