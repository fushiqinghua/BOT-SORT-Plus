# TCO v0.1 设计与交付复核

复核日期：2026-11-27。基础提交：`235fe4097066b5023cc84ca8cd6edd5757fd658c`。

**结论：设计、阶段协议、配置及准备工具的职责已经对齐，可以作为下一轮本地实施入口。TCO 网络、训练与在线跟踪尚未实现，本次复核不构成模型代码验收，也没有证明任何真实数据收益。**

## 1. 本次交付范围

已提供模块规格、T0–T4 实验协议、数据契约、文献与历史结果定位、本地实施交接、机器可读协议／任务表，以及可以运行的批次准备工具。已有 B、GMC、③④⑤和神经 Q/R 的代码与归档沿基础树保留。

新工具的四个入口为 `init`、`check`、`prepare`、`status`。它不加载跟踪模型、不读取完整图像或 GT 内容、不训练、不执行 TrackEval。网络及正式实验的具体实现任务在实验协议 I0–I6 中分解，尚不存在可直接运行的 TCO 训练或闭环命令。

### 复核中已经修正的歧义

1. 当前图像对照原有“关闭历史”措辞改为明确的同结构 `current_repeat`，防止分支容量成为混淆因素。
2. 删除“校准位移范围”，首版限幅固定；变更限幅需新版本与重新核算可达性。
3. 统一 `fit/calibration/holdout`，建议母视频比例 70/15/15；T0 核对来源，T1 导出前冻结。
4. 为 T1 增加正常、准确的低分观测控制类，保留被修坏的分母。
5. 将简单 GT clamp／有限搜索与严格上界分开，人工可见性作为独立抽样诊断。
6. 统一任务必需产物名称、T4 的条件状态和独立身份表征备选；历史打乱明确为固定 P3 的诊断，非第五训练臂。
7. 将“本身份 IoU”和“明确负例质量 0”统一为身份条件定位质量，避免与任意目标最高 IoU 混用。
8. 准备工具核验协议 schema、固定基准、任务依赖与自身源码摘要；旧批次不自动认证更新后的代码。
