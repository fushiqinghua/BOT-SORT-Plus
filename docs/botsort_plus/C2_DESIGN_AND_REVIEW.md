# C2：身份可信度约束的外观关联与记忆更新

## 1. 研究目标与边界

本模块接续 `iteration/v0.2-a2` 的实现和实验归档，采用 **YOLO11-M RGB–T + BoT-SORT + 微调 RGB ReID + B** 作为主要对照。A 的弱观测起轨保持关闭。既有 C 的 RGB/thermal 质量加权接口仍保留，但本轮新配置关闭旧 C，使用独立的 `identity` 配置段。

本轮要验证的假设是：几何关联成功并不意味着当前外观属于该身份；如果把存在身份竞争或历史冲突的观测直接写进模板，错误可能影响后续关联和 B 恢复。因此，**关联接受**与**外观记忆写入资格**需要分开判断。持续背景伪目标的存在性鉴别不属于本模块的保证范围。

既有 `AppearanceConfig` 的 crop quality 主要描述特征输入的可用性。C2 增加的是当前观测对某个历史身份的支持程度，包括历史一致性、同一轨迹的候选竞争和同一检测的身份竞争。该评分是确定性控制量，不是经过标定的身份概率。

## 2. 关联机制

令 \(G_{ij}\) 为该原生阶段的几何基础代价，\(C^{\mathrm{ref}}_{ij}\) 为现有 B_ref 的完整关联代价。对于 high 阶段，几何基础沿用既有 IoU 或按原生配置融合检测分数后的代价；unconfirmed 阶段沿用其原生分数融合与外观距离尺度。C2 不改变这两个阶段的匹配阈值和原生空间门控。

成熟可靠历史可用时，关联代价为：

\[
C^{\mathrm{C2}}_{ij}
=G_{ij}-r_{ij}\max(0,G_{ij}-C^{\mathrm{ref}}_{ij}),
\qquad 0\le r_{ij}\le1.
\]

这项操作只控制原有外观加成的强度：\(r=0\) 使用几何基础，\(r=1\) 恢复原来的加成。它不会让一个匹配比参考代价更便宜，也不会仅因为外观不可信而给已可接受的几何匹配添加惩罚。完整联合指派仍可能变化，不能据此承诺所有原有匹配都保留。

可靠历史使用经过写入门控的 RGB 单位向量锚点及其质量、有效更新次数。当前帧开始时复制历史快照，所有阶段只读该快照，因此当前观测不能通过先写入模板再证明自己匹配正确。

在可行竞争集合中，计算双向外观间隔：同一轨迹对其他检测的代价，与同一检测对其他身份的代价，分别减去当前配对代价，取最小值。历史一致性、该间隔和观测质量共同约束 \(r\)。竞争者虽然几何可行、但缺少可靠历史或有效外观时，竞争关系属于未知，不能删除该竞争者后制造一个很大的“可信间隔”。没有竞争者时使用绝对历史一致性作为支持，不把间隔设为正无穷。

具体而言，使用当前阶段进入联合指派的轨迹与检测矩阵，以原生空间门限建立可行集合。令单位锚点为 \(p_i^{t-1}\)，当前单位特征为 \(f_j^t\)，则 \(d_{ij}=1-(p_i^{t-1})^T f_j^t\)。令 \(m_{ij}\) 是上述双向间隔，定义

\[
h_{ij}=\operatorname{clip}(1-d_{ij}/\tau_h,0,1),\qquad
q_{ij}=\min(q_i^{t-1},q_j^t).
\]

有竞争者且其历史/特征均已知时，\(s_{ij}=\operatorname{clip}(m_{ij}/\tau_m,0,1)\)；存在未知竞争者时 \(s_{ij}=0\)；确实没有几何可行竞争者时 \(s_{ij}=h_{ij}\)。成熟状态的 \(r_{ij}=q_{ij}h_{ij}s_{ij}\)。默认 \(\tau_h=0.40\)、\(\tau_m=0.10\)。所有分量均来自过去可靠锚点和当前观测，没有训练或概率标定步骤。

这一乘积会主动降低外观权重。例如单目标完全一致但 crop quality 为 0.35 时，\(r\) 至多为 0.35，并非完全信任外观。后续实验必须检查 `reliability` 的分布，避免整个系统普遍退化为主要依靠几何。日志中的 `geometry_cost` 是门控用原始 IoU 代价，`base_cost` 才是公式中的 \(G\)：unconfirmed 的分数融合会使两者不同。

**竞争范围是当前阶段，不是整帧所有身份。** high 已接受的轨迹不会再次加入 low/unconfirmed 的竞争矩阵。这保留分阶段匹配的含义，但无法保证识别跨阶段残余重复框造成的所有污染；例如另一身份已在 high 匹配，其残余低分框在 low 中可能不再面对该身份竞争。该边界需要在失败例中单独检查，不能把本版描述为全局身份排他机制。

明确的回退包括：

- 历史尚未成熟时，采用参考关联代价，并记录冷启动状态；不会把临时种子描述为成熟身份模板。
- 当前 RGB 缺失、零范数或质量不满足要求时，不授予外观加成；缺失不是距离零。
- 原生空间门控外的配对不会因为 C2 重新获得外观加成。
- low 阶段仍使用原有几何关联；B 仍由原 `RecoveryMatcher` 决定恢复，不用 C2 的关联评分替换 B。

## 3. 记忆写入机制

身份记忆包括三条需要区分的状态：原生 `STrack` 的 `smooth_feat/curr_feat/features`，供 B 使用的 `MemoryBank`，以及 C2 自身的可靠历史锚点。只门控自定义 bank、却允许原生 `track.update()` 先写 `smooth_feat`，不能实现该设计。

本版规则如下：

| 阶段 | 跟踪行为 | 外观写入行为 |
|---|---|---|
| 原生高分出生 | 沿用原生出生门槛和 ID 分配 | 质量合格的 RGB 可作临时种子；需后续有效写入达到 `min_history` 才视为成熟历史 |
| high / unconfirmed | 使用所选关联模式的联合指派 | 写入要求输入质量合格，并满足历史一致性及竞争约束；冷启动另要求强且有间隔的几何证据 |
| low | 沿用原生几何续轨 | 仅在可靠历史和当前证据允许时写 custom bank；不会新增原生 low 的 `smooth_feat` 写入路径，也不会靠 low 凭空建立可靠锚点 |
| B 恢复 | 保留原 B 的候选验证、恢复与 ID 继承 | 恢复当帧隔离外观写入；后续满足条件的原生匹配可恢复写入 |
| 拒绝写入 | 几何、生命周期和已经接受的 ID 仍正常更新 | 冻结该阶段原本可能写入的原生与自定义外观状态 |

匹配后才提交本次有效锚点更新。同一身份在同一帧不得重复提交。序列内只保留仍存活身份的状态，不积累无限历史，不读取 GT，也不回填过去输出或修改过去 ID。

`recovery.py` 和 `candidates.py` 的算法文件保持不变。这只表示保留 B 的规则；启用 C2 写入门控后，B 读取的记忆可能变化，因此 B 的实际恢复结果也可能变化。只有关闭 C2 或使用观察模式时，才要求参考输出严格一致。

## 4. 开关与可解释消融

`identity.enabled` 是总开关。`association_enabled` 控制 high/unconfirmed 的外观加成约束；`memory_enabled` 控制原生及 custom bank 的写入门控。两项均关闭时应使用总开关关闭配置。`observe_only=true` 只维护诊断所需的辅助状态并记录拟议决定，原生代价、记忆和 B 状态继续沿用参考路径。

“仅关联”组仍需要私有可靠历史来计算关联可信度，但不拦截原生/custom bank 写入。它与“仅记忆”组分离的是对跟踪器的两个干预位置，不是声称前者完全没有历史状态。

本轮限定为 v2、A 关闭、旧 C 关闭、`with_reid=True` 的 RGB 方案。已有融合检测缓存可以继续使用，但 C2 不声称新增了 thermal ReID 编码器或重训了检测器。

## 5. 设计到代码的复核清单

实际软件运行结果、旧版本差分回放及独立复核记录见 [validation_v0.3/VALIDATION.md](validation_v0.3/VALIDATION.md)。下表列出设计要求与相应证据位置；真实数据准确率不在软件验收范围内。

| 设计要求 | 对应代码/验证位置 | 验收证据 |
|---|---|---|
| 明确配置、非法组合失败 | `identity_reliability.py`、`config.py` | 配置验证测试 |
| 可信度有界、代价位于参考与几何之间 | `identity_reliability.py` | 端点、随机矩阵、空矩阵和非有限输入测试 |
| t−1 快照因果性 | `identity_reliability.py`、原生接入 | 同帧先后提交不改变本帧决策测试 |
| 竞争未知不等于没有竞争 | `identity_reliability.py` | 缺失/冷启动竞争者、并列间隔和单目标测试 |
| 续轨与写入分离 | 原生接入 | 拒写后仍输出 ID 和正常几何更新 |
| native/custom 双路径冻结 | 原生接入 | 实际对象状态断言，不能仅检查日志 |
| low 不新增 native 写路径 | v2 low 接入 | low 可信/不可信观测前后状态断言 |
| B 当帧隔离、后续可恢复 | v2 B 接入 | B 真正恢复后记忆不变，后续可靠帧可更新 |
| disabled / shadow 旁路一致 | 原生集成与 CLI | 每帧预测数组及 MOT 文件一致性 |
| 原 B/CandidatePool 文件保持 | Git 差异检查 | 对源分支内容校验 |

软件测试证明的是实现行为与设计的一致性。真实 HOTA、AssA、IDF1、IDSW 和 FPS 结论必须由冻结输入的回放与独立评估提供。当前默认阈值是待验证的设计初值，不是已优化参数。

## 6. 研究来源与局限

- [BoT-SORT: Robust Associations Multi-Pedestrian Tracking](https://arxiv.org/abs/2206.14651)：基线关联、运动与外观结合。实际集成代码来源和许可沿用 [PROVENANCE.md](PROVENANCE.md)。
- [History-Aware Transformation of ReID Features for Multiple Object Tracking，ECCV 2026](https://arxiv.org/html/2503.12562v2)：历史信息可以改变外观表示的有效性，为“历史条件化外观可信度”提供研究动机。本实现没有复现其 FLD 特征变换、广义特征分解或完整 HAT-SORT。
- [Focusing on Tracks for Online Multi-Object Tracking，CVPR 2025](https://openaccess.thecvf.com/content/CVPR2025/html/Shim_Focusing_on_Tracks_for_Online_Multi-Object_Tracking_CVPR_2025_paper.html)：参考轨迹视角组织关联的研究方向。本实现不声称复现其全部 TPA/TAI，也未使用被冻结 NMS 已删除的检测。

可在论文中讨论的贡献是针对当前微小目标系统，对“外观如何参与关联”和“何时可以改变身份历史”给出相互配合、可消融且因果在线的具体规则。是否构成有效改进，仍取决于真实数据收益及失败例分析。

当前局限包括：错误初始种子可能影响后续判断；过于保守的写入门控可能减慢视角变化适应；几何证据本身对微小目标有噪声；恢复当帧隔离可能减少有用更新；同一序列有大量几何可行竞争者时，成对比较成本上升。逐序列指标、写入覆盖率、冷启动占比和门控原因应与总体指标一同检查。

本版允许渐进、与历史一致的外观变化持续更新，但没有实现持续突变外观的自动重置。与错误种子持续冲突的真实观测可能一直被拒写；不能据此声称已经解决全部身份修复问题。额外的私有锚点、native EMA 与 custom EMA 也不是同一个向量。low 更新会改变 custom EMA 和私有锚点，native EMA 保持不写，测试明确保留这种既有区别。

计算上使用批量余弦距离，代价为 \(O(NMD)\)；竞争统计通过每行/列的第一、第二最小值及未知数量计算，为 \(O(NM)\)，不逐对再次遍历全部竞争者，也不引入 1280 维特征分解。这里 \(N,M\) 是该阶段轨迹和检测数量，\(D\) 为缓存特征维数。实际 FPS 仍必须测量完整回放。
