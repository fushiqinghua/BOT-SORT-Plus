**分支：`research/vttiny-weak-evidence`**  
**承接结果：`b734690e7af42f67be49eb3eec603a2b3d9a3683` 的 R3 归档**  
**补充进展：`6b7da02db7a5f93c12162822ef5861ff69fb6e22` 已归档 R4 探索性闭环**

本批实现 W0、W1、W2、W3 四组固定对照，并重算 W_old 严格外观门作为历史参照。复用已有 R3 的冻结状态、S0 候选、特征和离线标签，在 CPU 上完成评分与一对一指派，不运行检测器、ReID 网络或在线跟踪更新。

[本地执行](LOCAL_RUNBOOK.md) · [结果记录](RESULTS_TEMPLATE.md) · [归档目录](../../../results/vttiny/wem_r3_1/README.md) · [原 R3 结果](../../../results/vttiny/wem_v0.1/r3/README.md)

## 1. 本批要回答的问题

上一轮校准的 206 个已确认条件机会都有可用历史，余弦门设为 0.75 后只保留 9 个，设为 0.85 后保留 0 个。留出对应为 219、29、6。后续运动门没有继续删除这些通过外观门的正确机会。原生几何对照仍保留较多正确机会，但同时采用许多身份未决候选。[逐门统计](../../../results/vttiny/wem_v0.1/r3/calibration/gate_breakdown.json)

本批区分三个问题：

1. 在不强制要求 RGB 高相似度的情况下，历史运动是否改善弱候选选择？
2. 将 RGB 仅作为软排序证据，是否改变真正存在竞争的关联，并改善选择结果？
3. 在此基础上增加相对身份竞争，是否减少错误或未决采用，同时保留有用机会？

新增 [R4 探索性闭环归档](../../../results/vttiny/wem_v0.1/r4/README.md) 已完成官方 30 段八组回放。其探索点采用余弦下限 0.75、运动下限 0.25、效用下限 0.55、双向间隔 0.05；完整 W 在 B 上少漏 59 帧、增加 145 个 FP，归档的 HOTA 变化为 +0.018 个百分点、MOTA 为 −0.048 个百分点，默认 R3 策略仍保持拒绝全部。这些结果进一步要求查清筛选与误接的来源，但它们没有执行本批 W0–W3 的固定状态消融；本批不重复旧 R4 八组。

这是一次固定状态的机制诊断。结果不直接等于 FN 减少量、KF 后验改善量或 HOTA／IDF1 增益。原 R3 的 `REJECT_ALL_FALLBACK` 仍作为原批次决定保留，本批不重新解释或覆盖它。

## 2. 共同输入与不变条件

参考固定为 **`B_early_moderate`**。本批没有生成 `evidence_both` 或其他 B＋GMC 参考的候选，不能将结果解释为相机模块组合收益。

完整输入继承 R3 训练侧划分：

| 分区 | 片段数 | 视频帧数 | 本批用途 |
| --- | ---: | ---: | --- |
| fit | 51 | 18,999 | 固定方法的分布与机制诊断 |
| calibration | 11 | 4,366 | 固定方法的对照与案例分析 |
| holdout | 12 | 5,566 | 继承分区上的开发诊断 |
| 合计 | 74 | 28,931 | 同一冻结候选集合的离线比较 |

这些分区采用代理来源组隔离，官方母视频映射尚未核实。旧 holdout 已被上一轮详细分析，本批明确将其视为已查看的开发诊断分区，不再宣称是新方法的未触碰盲测。历史检测器和 RGB ReID 曾使用官方测试数据选模或校准，仍保留这一限制。[来源凭据](../../../results/vttiny/wem_v0.1/r3/calibration/source_receipts.json)

所有方法使用相同的原始候选与共同资格：

- 继承帧首已确认活跃、原生与 B 处理后仍未取得常规观测的轨迹资格。
- 只使用缓存中真实 S0 行，保持原始框、原始分数、序列／帧／轨迹／检测行键。
- 继承正式预测 IoU 至少 0.50、实际适用的 GMC 保护、消费与预留所有权、近重复排除。
- 每条轨迹最多使用按原生几何顺序排列的 5 个坐标组参加最终指派。
- 一条轨迹和一个坐标组在一帧内各最多采用一次，保留不匹配选项。
- 不产生新 ID，不改 KF，不写外观记忆，不改变 B 或 GMC 的状态。

离线标签仅参与结果统计。评分、竞争和指派不能使用 `identity_label`、GT 身份、是否为漏检机会或来源组来选择候选。

## 3. 固定方法定义

定义：

- `i`：原始弱框与正式预测框的 IoU。
- `m`：既有 R3 缓存的历史运动一致性，范围为 0 到 1。
- `c`：既有 R3 缓存中，当前弱框与有效历史外观的余弦中位数，范围为 −1 到 1。
- `a = (c + 1) / 2`：将余弦映射至 0 到 1，用于软排序。

`m` 的计算沿用原缓存：把过去真实观测中心经过 GMC 对齐，拟合时间趋势，以当前预测框对角线归一化中心偏差。`c` 也沿用同一个冻结 RGB 编码器与原裁剪；本批不重新提取特征。

| 方法 | 额外资格 | 匹配效用，越大越优 | 研究作用 |
| --- | --- | --- | --- |
| **W0** | 无 | `i` | 重算原生几何参考 |
| **W1** | `m` 存在且 `m >= 0.25` | `(i + m) / 2` | 几何＋历史运动 |
| **W2** | 与 W1 相同 | 有外观时 `0.4*i + 0.4*m + 0.2*a`；无外观时退化为 W1 | 外观仅辅助排序 |
| **W3** | W2 资格，加第 4 节相对竞争 | 与 W2 相同 | 相对外观竞争的附加作用 |
| **W_old** | 复现旧严格外观与竞争规则 | 旧 `history_score` | 历史参照，不属于四组新增方案 |

W_old 采用旧 `history_competition` 固定点：`c >= 0.85`、`m >= 0.25`、`history_score >= 0.55`，旧行／列未知竞争标记均不成立；已有行／列间隔若存在，需至少 0.05。其旧综合效用包含检测分数，完整沿用原规则。

这里的 W_old 是原 R3 的 **0.85** 固定对照，与已归档 R4 的 **0.75** 探索点分开记录。不能将 W_old 的离线计数称作对 R4 的在线重现。

W_old 与 W2 的综合效用组成也不同，因此 W_old 是历史参照，不能称作“仅去掉硬外观门”的严格单因素对照。硬外观门的损失位置由原 R3 逐门统计定位；本批主要单项比较是 W1→W2 和 W2→W3。

W1、W2、W3 不使用额外综合效用阈值；W2 不设置绝对余弦门。权重 0.4／0.4／0.2 是本批固定设计值，没有通过本批结果搜索或学习。原始检测分数只保留为相同效用下的稳定择优依据，不在 W1–W3 中额外混入另一项主效用。

### 为什么不再给 W2 加总效用硬门？

如果在改变效用公式时再加一个共同数值阈值，外观较弱可能再次导致候选被整体拒绝，使“软外观排序”混入隐性外观准入。此轮先隔离排序作用：共同资格由几何与历史运动确定，外观通过效用影响可行边之间的选择。

**若一条轨迹只有一个可行候选且不存在跨轨迹冲突，W2 可能与 W1 完全一致。** 这种结果说明排序证据没有施展空间，不能通过临时增加余弦阈值来制造差异。需结合竞争机会数和实际改变的指派来判断外观是否发挥作用。

W1 与 W2 使用相同的可行边集合，但最大总效用匹配在冲突图中可能改变采用数量：较高效用的一条边有时会取代另一组较低效用的边。因此不能要求两组采用数始终相等，也不能只用采用数变化代表准入资格发生改变；应回到逐边资格和指派结果分别核验。

## 4. W3 相对竞争的准确范围

W3 比较纯外观余弦，而不是继续使用旧的混合 `history_score` 间隔。两类比较均在最终 top-5 裁剪之前进行：

1. **同行竞争**：同一旧轨迹面对其他不同坐标组的弱候选。当前余弦减去其他候选组中最大余弦。
2. **同列竞争**：当前弱候选面对其他可能身份。使用缓存的 `challengers`，包含已匹配邻居对自身身份的支持，不能仅查看尚未匹配轨迹。

有竞争时，对应间隔需至少为 **0.05**。两类竞争分别记录：

- 没有竞争者：标记为不适用，继承 W2 的决定，不把间隔伪造为很大的值。
- 有竞争者且比较特征完整：计算真实间隔并执行比较。
- 有竞争者，但自身或任何需要比较的竞争外观缺失：标记为不可判并拒绝该边，不能把缺失竞争分数当作零。

同坐标的重复检测共享一个候选组，不应互相构成同行竞争。被 top-5 裁掉的其他坐标组仍可影响竞争判断，避免因裁剪制造“唯一候选”。

同行竞争沿用通过几何和所有权检查的全量候选集合，其中也包括运动证据缺失或未通过 W1 运动门的其他坐标组，不限定为 W1 最终可行集合。因此 W3 的“比较信息缺失”与真实间隔不足必须分开报告。

相对优势回答“更像哪个身份”，不能单独证明该框中存在目标。背景或长期静态结构也可能相对所有其他身份更像某条旧轨迹。背景接纳必须继续依靠独立标签与案例复核评估。

## 5. 执行顺序与分析顺序

1. 按 [本地执行](LOCAL_RUNBOOK.md) 创建本地配置，指向既有 R3 分数缓存、标签和冻结划分。
2. 执行输入检查，核对参考、来源摘要、逐序列覆盖和标签对应关系。
3. 在新的输出目录运行固定五组方法，保留全部方法结果。
4. 先核对 W0 和 W_old 与原 R3 对照是否一致，确认新工具没有改变共同输入或历史规则。
5. 依次比较 W1−W0、W2−W1、W3−W2，而不是只查看最大正确采用数。
6. 从方法差异和未知采用队列中安排人工复核，记录无法裁决的案例。
7. 填写 [结果模板](RESULTS_TEMPLATE.md)，形成继续／修改／停止的明确研究结论。

完整缓存可直接执行本批完整诊断。若使用既有 smoke 缓存，只能验证输入和流程，不应把其小样本数字填入完整结果表。

## 6. 必须保留的计数与解释

| 统计 | 单位与用途 |
| --- | --- |
| 候选资格、拒绝原因、实际指派 | 跟踪身份与候选组的关联边；区分外观缺失、运动不合格、相对竞争失败和一对一未选中 |

| 正确条件覆盖 | 去重的 GT 目标帧；不能与候选边混用分母 |
| 漏检 episode、来源组 | 判断收益是否集中在同一轨迹或少数场景 |
| 方法间指派变化 | 区分多采用、少采用和改选其他候选；检查新增正确是否伴随新增错误或未知 |
| 外观及竞争适用范围 | 区分无外观退化、无竞争、不完整比较、实际有竞争；解释 W2/W3 是否有作用空间 |

原 R3 校准机会高度集中于 `DJI_0067_2`。本批必须同时查看逐序列和来源组表。大量相邻帧不能被当成同样数量的独立实验。

旧 R3 的负例数量仍然稀少；本轮固定方法比较可以输出诊断结果，但不会因脚本成功或某分区零已知错配自动产生线上启用点。无法计算的背景风险应明确保留为不可核验，不填作 0%。

## 7. 结果如何决定下一步

| 观察结果 | 支持的解释与下一步 |
| --- | --- |
| W1 相对 W0 减少错误／未知，且保留多个来源的正确机会 | 历史运动具有筛选价值；继续研究运动主导的弱证据接纳 |
| W2 相对 W1 在实际竞争中改选更正确的候选 | 支持外观作为软关联证据；再检查是否跨来源稳定 |
| W2 与 W1 完全相同且竞争很少 | 当前数据没有足够排序机会；不据此宣称外观完全无用，也不继续扩大权重网格 |
| W3 减少可确认错误，且正确机会损失有限 | 相对竞争可能有增量；进一步复核其拒绝案例 |
| W3 主要因特征缺失拒绝正确机会 | 先审视比较可用性，不立即堆叠更多竞争门 |
| 新方案主要放行未知候选 | 暂不能认定有收益；优先审阅实际采用的未知并集 |
| 正确机会极少、仅单来源有效，或新增错误抵消覆盖 | 停止当前方案或缩小研究范围，保留负结果 |

若本批支持新的关联规则，后续应结合 R2 的预测／原始弱框／KF 后验证据，复用已有 R4 的一致性核验与 Coast-only、W-coast、完整 W 对照框架，另行验证新规则。本批 R3.1 不运行 R4，也不生成新的 HOTA／IDF1 数值；已归档 R4 的事实继续单独保留，不据此声称新 W0–W3 已在线有效。
