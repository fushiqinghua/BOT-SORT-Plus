## 理论与实现复核

| 设计要求 | 实现与验证 |
| --- | --- |
| W0 原生几何对照 | 原始排序/一对一/同框组，与历史函数对照 |
| W1 几何与运动 | 运动下限 0.25，效用 (i+m)/2 |
| W2 外观只参与排序 | 与 W1 可行边一致；缺失时回退，不加绝对余弦门 |

| 复用同一批证据 | 输入字节摘要、原框/分数/快照/范围核验 |
| 不把脚本成功当性能提升 | 离线完成与科研 NOT_EVALUATED 分开记录 |
