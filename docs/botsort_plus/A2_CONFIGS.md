# A v0.2 配置与消融矩阵

这些配置是可执行的开发实验设置。`0.18`、`0.20` 等阈值尚未经过新版真实数据集回放验证；不能据此预告 HOTA、IDF1 或 FP 的改善。C 在本轮所有新增配置中均关闭。

## 版本与开关

- `adapter_mode="legacy"`：原 v0.1 接入路径。原 `00`—`11` 配置文件保留不变，不会因为升级自动启用 A2。
- `adapter_mode="v2"`：使用新版接入流程、基座一致性处理和弱起轨提交。配置 `12`—`26` 显式选择此路径。
- `birth.enabled`：是否允许 A 的弱观测起轨；关闭时，新存在确认和身份约束不会创建新 ID。
- `recovery.enabled`：B 的短轨迹身份恢复开关。A 不负责恢复旧 ID。
- `birth_policy.mode`：E 的确认方式，见后表。
- `birth_identity.enabled`：I 的出生前旧身份竞争检查。关闭 I 不会关闭 B 已有的恢复和 reservation。
- `birth_policy.observe_only=true`：记录 A2 的真实判断，但不提交 A 的新轨迹；不能据此消耗正式观测、抑制原生高分起轨、写入正式身份记忆或改变 B 的输入。

E、I 关闭时仍有 v2 共用接入流程。因此 **`A1_ref` 不等同于历史 A，`A1B_ref` 不等同于历史 AB**。它们是相同 v2 基座上的旧确认规则对照。历史结果继续保留；如基座变化导致输出差异，应单独报告，不计为 A2 算法收益。

## 四种 E 模式

| `birth_policy.mode` | 准入条件 | 最早连续确认时间 |
|---|---|---|
| `legacy` | 调用原 `Candidate.ready()`，使用原 A 命中数与几何/分数累计证据 | 默认第 3 次观测，仍取决于原累计证据 |
| `score_window` | 当前帧有检测，最近 5 帧至少 3 次命中，均分 ≥ 门槛 | 第 3 次观测 |
| `fixed_window` | 当前帧有检测，最近 8 帧至少 5 次命中，均分 ≥ 门槛 | 第 5 次观测 |
| `two_stage` | 第一阶段 3/5 + 均分；随后 3 个实际帧内至少 2 次新观测，后续观测均分也合格 | 第 5 次观测 |

新模式不使用候选的旧 `evidence` 作为存在确认依据。几何仍用于共享候选连接和池管理，并未被删除。`legacy` 中列出的 `mean_score` 等新字段不生效。

`two_stage` 的后续观测必须严格晚于 `armed_frame`。失败轮次不能复用为新的确认；A 的失败不删除 B 可用的候选历史。因身份歧义而暂缓的新轨，实际提交前仍须检查近期复核支持，旧 ready 不能永久通行。

`fixed_window` 与两阶段模式都最早在第 5 次连续观测确认，但有间断时延迟不一定相同。因此它是**近似延迟对照**，仍需统计确认延迟分布，不能声称已经严格匹配延迟。

## 推荐执行顺序

1. 保留原 `00_baseline`、`05_B` 的结果与配置，核对升级后 legacy 路径。
2. 运行 `12_baseline_ref`、`13_B_ref`，把基座差异单列；运行 `25`、`26` 检查观察模式输出是否与对应参照一致。
3. 运行 B 基础上的二因素矩阵：`21_A1B_ref`、`17_A2B_E`、`18_A2B_I`、`19_A2B`。
4. 补充 `16_A2`，判断 A 自身收益及其对 B 的依赖；需要完整 A-only 二因素矩阵时再加 `20`、`14`、`15`。
5. 运行 `22`、`23` 区分分数支持、确认延迟和后续复核的作用。`24` 仅改变均分门槛为 0.20。

所有组共享同一份冻结检测、RGB ReID 特征、原始图像、GMC 和评估协议。输出使用各自实验名，不覆盖旧结果。主要结论比较 `A2B` 与 `B_ref`；同时保留与历史 B 的绝对结果对照。

评价需要包含 HOTA、IDF1、DetA、AssA、MOTA、FP、FN、IDSW、相对 B 的逐 GT 目标帧新增/丢失覆盖、起轨当帧换号和弱轨 FP 寿命。不能只比较 A2 的弱轨 TP 数，也不能把原 A 起轨记录上的事后分数筛选当成新算法回放结果。
