# 理论到代码：机制与复核

## 1. 固定主基线和本版作用范围

主基线为 **YOLO11-M RGB–T + BoT-SORT + 已微调 RGB ReID**。检测器、检测缓存、RGB 坐标参考、七类合并为 object、15 FPS、SOF GMC 与原评估口径继续沿用。虽然检测器使用 RGB–T，原 ReID 只看 RGB 裁剪；C 才增加独立的 thermal 身份证据。

新增逻辑位于独立包 `botsort_plus`。`BoTSORTPlus` 是真实 BoxMOT `BotSort` 的子类，使用其 STrack、KalmanFilterXYWH、GMC、轨迹状态和输出合并。全关闭时直接调用原 `BotSort.update()`。开启时按锁定源码的阶段顺序执行，并在初始化之前插入 B/A；没有后处理全视频身份合并。

BoxMOT 接入锁定 16.0.11 wheel 中的关键文件 SHA256。该 wheel 的包内 `__version__` 字符串仍是 16.0.10，故不依赖这个字符串判断兼容性。保护的是实际接口和算法源码。部署时应复用原 baseline runtime。

## 2. A：时序弱观测起轨

### 2.1 候选输入和几何连接

原生高分、低分、未确认轨迹关联先消费检测。只有剩余检测进入候选池；A 不抢占已关联检测。候选既可来自原生低分段，也可来自高于高分门限、低于新起轨门限的残余检测。

候选池不分配公共 ID。每个候选保存短期观测、最近工作框、残差速度、证据和漏观测次数。工作框与速度使用当前 SOF 仿射矩阵补偿相机运动，历史观测保持其原帧坐标，以便 B 与同帧预测比较。

`geometry_cost()` 组合 IoU、中心位移与宽高比例。小目标降低 IoU 权重、提高中心距离权重；中心尺度有像素下限，位移有绝对像素上限，宽高比例有门限。4×4 框同时在 x/y 方向移动 1 像素时 IoU 仅为 9/23，这正是加入中心项的动机。

连接使用带拒绝项的一对一分配。行、列最佳和次佳的 margin 在删除竞争边之前计算，不能通过先删掉对手制造出一个看似确定的匹配。

### 2.2 证据更新与确认

代码执行：

\[
E_t=\max\{0,\rho E_{t-1}+h_t[\alpha\tilde s_t+(1-\alpha)e^{-D_g}]-\lambda(1-h_t)\}.
\]

`max(0, ·)` 是实现增加的非负截断，防止过期候选保留无限负证据。置信度按 `score_low / score_high` 归一化并截断。默认最近 5 帧命中至少 3 次、证据达到 1.2，且当前帧必须有真实检测。`fixed_hits` 消融只保留窗口命中条件。

已消费检测框和更新后的轨迹框共同用于重复抑制。歧义观测不会增加证据或复制候选；候选数、连续漏帧与寿命有上限。与已消费轨迹冲突的候选在本轮证据更新前失效。

确认后由适配器新建原生 STrack，并标为已激活，因为候选池已经完成多帧确认。此前帧不回填。尚无真实 ReID 特征的低分新轨迹暂时只使用几何，后续出现真实特征再更新；不使用零向量构造外观。

## 3. B：短轨迹身份恢复

### 3.1 搜索与验证分离

每一帧在原生 KF 预测和 GMC 之后、检测更新之前，保存该帧预测框及投影中心协方差。B 逐条将候选历史观测与**对应帧**的预测比较，不把当前预测倒推为虚假的历史证据。

协方差只用于放宽有限搜索门：

\[
r_{gate}=\min(r_{max},r_{scale}+k\sqrt{\lambda_{max}(S_{xy})}).
\]

中心距离代价仍使用固定尺度归一化。因此，更大的协方差不会让一个原本有限的代价变小。绝对位移和尺度门继续生效。

### 3.2 恢复代价和拒绝

恢复代价包含短轨迹各帧几何代价均值、可信外观代价均值和时间惩罚。尺度一致性已经包含在几何项，不再另算一个重复的尺度项。缺少外观时对剩余权重重新归一化，缺失值不是零距离。

当前高质量外观若明显否定旧身份，即使过去外观接近也拒绝恢复。候选必须达到默认 3 次观测，当前帧命中，历史不能与旧轨迹最后观测帧重叠，每帧预测必须存在，旧身份不能超期。

带拒绝的一对一匹配和双向歧义 margin 同时生效。未达确认次数的竞争候选也参加歧义比较。潜在恢复候选可预留最多 5 帧，阻止 A 或原生高分初始化提前建立新 ID；预算不会因中间缺帧而重置。候选连接本身模糊时，该帧的高分检测也不能绕开候选池直接起轨。

### 3.3 状态更新

适配器处理顺序为：**读取旧记忆 → 计算全部恢复代价 → 一对一决策 → 原生 STrack.re_activate(new_id=False) → 更新可信外观**。成功恢复的轨迹从当帧局部 lost 列表清除，防止同一 ID 同时进入 active 和 lost。候选只消费一次。

本版 B 是追加在原生关联之后的残余恢复，不会撤销原生错误匹配。也没有“所有目标一律等 3 帧”的延迟：原生直接恢复仍然即时完成，只有补充路径需要短轨迹验证。

`age = current_frame - last_detection_frame`，与两次观测之间的缺失帧数相差 1。实验分桶时必须区分这两个量。默认 B 的最大 age=30，与当前原生保留范围对应；长窗口实验必须显式同步增大 native buffer，并运行仅增大 buffer 的对照。

## 4. C：质量感知双模态外观与记忆

### 4.1 分模态距离

RGB、thermal 各自保存历史原型，只计算同模态余弦距离：

\[
\tilde d_m=(1-\cos(\mu_m,f_m))/s_m,\quad
w_m=\omega_m\min(q_m^{hist},q_m^{obs}),\quad
D_{app}=\frac{\sum_m w_m\tilde d_m}{\sum_m w_m}.
\]

两模态可以具有不同特征维度。`s_m` 为显式距离标定参数，默认 1 不是已经校准。两个模态都不可用时返回 `None`，由几何或拒绝机制处理，绝不返回零距离。

C 已接入高分和未确认轨迹的实际关联代价，也供 B 使用。原 BoT-SORT 的空间邻近门继续存在；C 不宣称单靠外观跨任意大距离关联。未确认阶段先用未缩放的 C 距离过门，再保留原生的代价缩放，避免隐式放宽门限。

### 4.2 质量与可信写入

质量代理在原始裁剪尺度上计算有效像素、裁剪比例、局部对比度和相邻像素梯度。它是**未标定的手工代理**，不等价于身份可分辨性，也不估计真实配准误差。浮点图像须事先规范到 [0,1]；整数热图按 dtype 最大值归一化。

低质量观测仍可更新位置，但不能污染可信身份记忆。RGB/thermal 原型分别按 EMA 更新，先验证整个包再写入，避免半写入。默认匹配质量门为 .15、更新质量门为 .35。4×4 原生像素裁剪的质量上限为 .25，默认不会更新记忆，这是保守初始化，应通过尺度分组的覆盖率和消融判断是否过严。

`weighting=fixed` 只去除融合权重中的 pair-quality 因子；有效性门和记忆更新门保留，作为单因素权重对照。`weight_thermal=0` 是 RGB 质量记忆对照。

### 4.3 真实输入通路

导出器实际加载 baseline 微调 CLIP-ReID，逐 tensor 检查视觉状态一致，并为低分检测提取真实 RGB 特征。thermal 通路实际执行用户提供的 TorchScript 编码器，要求显式输入尺寸、通道、均值和标准差。

空间对应需明确声明为已对齐，或提供 RGB→thermal 单应矩阵；不能仅因两张图尺寸相同就推断已配准。映射四角、裁剪比例和无效区域均有处理。这里的全局单应矩阵只是本版支持的接口；动态视差、逐帧配准属于后续扩展。

不附带虚构的 thermal 训练结果。如果没有 thermal 编码器，可先完整验证 A/B，以及 C 的 RGB 质量记忆对照；C 的完整 RGB–T 精度收益要在真实 thermal 特征准备好后测量。

## 5. 与前序理论的一致性核对

|理论要求|代码位置|本版结果与边界|
|---|---|---|
|弱观测经过时序确认才起轨|Candidate.ready / CandidatePool.update|已实现，当前帧输出，支持单帧和固定窗口消融|
|微小框降低纯 IoU 敏感性|geometry_cost|已实现，中心项、尺度项、像素下限与上限|
|不确定性扩大范围不能提高身份确信|geometry_cost|已实现，有限代价不随协方差增大而改善|

|低分零向量不能充当 ReID|FeatureCache / _features / appearance.py|已实现，缺失或非法高分特征明确报错|

## 6. 本轮复核修复的问题

- 无特征的 A 新生轨迹进入原生 embedding_distance 的风险：增加有效外观判断和几何回退。
- B 恢复对象同时保留在本轮 lost 列表：在合并前清理。
- 候选池拒绝的高分观测绕道原生新起轨：统一尊重抑制/歧义结果。
- C 未确认轨迹门限被距离除以 2 意外放宽：先过原始融合距离门。
- NaN / inf 歧义 margin、异常配置和未来帧：加入严格校验与反例测试。
- 同权重、不同检测缓存被误当冻结输入：校验完整检测内容指纹。
- 不同序列混用 thermal 编码器/预处理：核对编码器契约一致性。
- 缺失、零向量、缓存错位、SHA 不符、维度/范数异常：在回放前拒绝。

本版没有承诺具体指标增幅。实际验证应分别检验 A 是否降低 FN 却增加过多 FP、B 是否降低 IDSW 却产生错误恢复、C 的有效特征覆盖与质量权重是否带来一致改善。已有方法解决类似问题并不排斥本章的场景化改进；论文应准确说明借鉴结构、具体改变和对照证据。
