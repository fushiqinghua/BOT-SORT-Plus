## 1. 要由实际指标回答的问题

R3.1 已完成冻结状态下的 W0–W3 对照：W1 保留已知正确覆盖并少采用部分未知候选；W2 没有改变最终选择；W3 失去了部分正确覆盖。这些结果只能解释候选选择，不能替代接纳弱框后完整轨迹的 HOTA、IDF1、MOTA、FP、FN 和 IDSW。

本批将四种接纳策略接入原生 BoT-SORT＋模块 B 的实际执行链路。每个变体独立从序列首帧运行，弱框被接纳后真实更新轨迹状态；后续预测、原生关联和 B 的恢复事件可以随状态分叉而变化。完整序列的输出由同一版 TrackEval 评测，最终依据实际指标、逐序列分布和错误传播判断是否保留该模块。

本批不设置“R3.1 必须先有正收益”或“785 条未知候选必须先全部人工复核”的启动条件。短序列 smoke 用于检查接口与关闭模式一致性；技术检查通过后，十组完整评测都要运行，不能因为中间某组指标较差就删掉该组。

## 2. 完整实验矩阵

两套参考分别为：

- **B**：冻结的 `B_early_moderate`。
- **BG**：冻结的 `evidence_both`，包含既有 B、GMC 及该参考的其他既定配置。不得在本批重新调整这些配置。

| 组名 | 接纳策略 | 与其比较的参考 | 要回答的问题 |
| --- | --- | --- | --- |
| `B_off` | 关闭新增弱观测接纳 | 既有 B 归档 | 复现 B 参考 |
| `B_W0` | 几何选择 | `B_off` | 直接补接 S0 是否产生净收益 |
| `B_W1` | 几何＋历史运动 | `B_off`、`B_W0` | 运动条件与排序是否改善闭环结果 |
| `B_W2` | W1＋软 RGB 排序 | `B_off`、`B_W1` | 外观排序是否带来真实增量 |
| `B_W3` | W2＋相对外观竞争 | `B_off`、`B_W2` | 相对竞争能否改善误接与正确覆盖的交换 |
| `BG_off` | 关闭新增弱观测接纳 | 既有 BG 归档 | 复现 BG 参考 |
| `BG_W0` | 几何选择 | `BG_off` | 在现有相机模型基础上的弱观测增量 |
| `BG_W1` | 几何＋历史运动 | `BG_off`、`BG_W0` | 运动证据与现有相机模型能否共同工作 |
| `BG_W2` | W1＋软 RGB 排序 | `BG_off`、`BG_W1` | 软外观在 BG 上的增量 |
| `BG_W3` | W2＋相对外观竞争 | `BG_off`、`BG_W2` | 相对竞争在 BG 上的增量 |

**必跑范围为同一份冻结清单中的全部 30 段。** 不能按本轮结果挑选表现较好的序列。此前完整回放覆盖 12,590 帧，实际长度应从冻结协议读取并核验。官方 30 段此前已经反复用于研究与选模，本批按开发评测集解释，不重新宣称是未触碰测试集。

`BG_Wk` 的主差值必须相对 `BG_off`，不能相对 `B_off` 后把 BG 自身已有收益归到 W。两种基础上的增量差另行报告为 `(BG_Wk − BG_off) − (B_Wk − B_off)`；它描述组合增量，不能单独证明因果协同。

## 3. 接入位置和共同约束

接入顺序为：原生高分关联、低分关联、未确认轨迹处理、B 的既有恢复及原生建轨完成后，W 检查本帧仍缺少常规观测的合格旧轨迹。W 只使用本帧真实 S0 检测行，不生成新 ID。

四个变体共同保留原 R4 的外层资格：

- 帧首为已确认活跃轨迹，当前原生与 B 处理后仍缺少常规观测；
- 独立锚点已经获得连续常规观测支持，最近观测在前一帧，且本次弱更新预算尚未使用；
- 锚点与正式预测满足既定几何一致性；
- 原始检测分数处于既定 S0 范围，正式预测 IoU 至少 0.50，实际适用的 GMC 备用预测保护通过；
- 候选没有被原生流程消费、没有被 B 预留，且通过与已使用观测的近重复保护；
- 各轨迹按原生几何次序最多选择前 5 个坐标组参加最终指派，同帧一对一；
- 候选与其他输出的兼容性由原生最终整理流程预检查；无法保留既有其他轨迹输出的接纳不提交；
- 弱框采用原始坐标和原始分数，以 `new_id=False` 更新原轨迹；沿用原 KF，不写入弱框外观记忆，不把弱框当成新的常规身份锚支持。

这些共同规则在 W0–W3 之间保持一致。缺少或无法可靠提取当前 RGB 特征，不应在 W2/W3 评分之前额外删除几何候选；外观缺失的处理由各自的显式规则决定。否则，所谓“仅改变外观使用方式”的比较会混入候选池变化。

关闭模式必须复现原参考。启用后允许未来帧的原生关联、B 恢复与轨迹寿命发生变化，正是本批要评估的闭环作用。

## 4. 固定策略，不进行本批阈值搜索

令 `i` 为当前原始弱框与正式预测的 IoU，`m` 为经 GMC 对齐的近期真实观测趋势与当前弱框的运动一致性，`c` 为当前 RGB 弱框与有效历史 RGB 特征的余弦中位数，`a = (c + 1) / 2`。

| 方法 | 额外资格 | 指派效用，越大越优 |
| --- | --- | --- |
| W0 | 无额外运动或外观资格 | `i` |
| W1 | `m` 可计算且 `m >= 0.25` | `(i + m) / 2` |
| W2 | 与 W1 相同 | 外观可用时 `0.4*i + 0.4*m + 0.2*a`；否则使用 W1 效用 |
| W3 | W2 资格，再检查相对竞争 | 与 W2 相同 |

评分与指派复用 [R3.1 固定引擎](../../../tools/research/wem_r31/engine.py)。W1–W3 没有额外综合效用硬门；W2 没有绝对余弦硬门。现有 R3.1 的权重和阈值直接带入，本轮不根据完整评测结果反复调整后只汇报最好值。

W3 的行竞争是同一轨迹对其他不同坐标组的比较；列竞争使用其他可比身份，包括已取得常规观测的邻居。比较范围在 top-5 裁剪之前。存在完整竞争证据时，余弦相对间隔至少为 0.05；没有竞争者时不适用该门；有竞争者而比较特征缺失时记录不可判并拒绝。同行其他候选即使未通过运动条件，也仍属于原固定的比较范围。

R3.1 的历史 `W_old` 使用 0.85 绝对余弦门，旧 R4 探索点使用 0.75，两者不是同一工作点。本批十组主矩阵不混入这两个历史命名；历史指标可作背景，不能替代本批同协议对照。

## 5. 把解释性诊断放进闭环日志

`W_H` 定义为“W0 再要求 `m` 可计算，仍按 IoU 排序”。它仅作为同帧反事实诊断，不增加第十一、十二组完整回放，也不改变当前轨迹状态。原 R4 锚点通常已经保证两条近期常规历史；记录 W_H 可以直接核验这项条件是否在实际链路中冗余。

逐帧记录应能回答：

1. 原生及 B 处理后有多少缺观测轨迹，多少通过锚点、所有权和几何资格；
2. 近期常规观测数、`motion_unavailable`、`motion < 0.25` 分别出现多少；
3. 每条候选的几何、运动、外观、竞争状态、拒绝原因和最终指派；
4. W0、W_H 与当前策略的同帧选择差别；
5. 提议是否通过最终整理，是否正式提交，以及为何未提交；
6. 正式提交后，当帧补回、当帧未匹配与后续轨迹变化。

反事实选择在当前变体自己的在线状态上计算。不同变体已经分叉后，不能把两者日志中的全部候选差异称为同一固定候选池的单因素选择差异。W1 与 W2 的相同可行集断言只适用于同一输入帧的策略计算，不要求两组整段在线候选始终相同。

预测子进程不接收 GT 路径、候选是否为漏检机会或人工标签。启动前主进程核验 GT 文件摘要以固定评测输入；标注内容的解析、匹配和归因只在预测文件完成后的独立评测阶段执行。

## 6. 评测与解释顺序

### 6.1 首先确认完整执行

十组都必须覆盖同一 30 段及相同帧数，冻结检测、常规 RGB 特征、相机补偿、原生与 B 配置一致。关闭组应与既有参考输出一致。技术错误应修复后重跑受影响部分，不能把缺失序列按零分参与汇总。

软件检查通过只说明实验执行可靠；不得写成“模块有效”。指标负收益也不能被当作实验执行失败而删除。

### 6.2 再看完整指标

主表使用 TrackEval 的 **COMBINED** 聚合，不能用 30 段 HOTA 的简单均值代替。报告 HOTA、DetA、AssA、IDF1、MOTA、FP、FN、IDSW，并保留逐序列变化。百分制指标的差值用“百分点”。

先比较每组与各自 off 参考，再比较 W1−W0、W2−W1、W3−W2。除总体指标外，列出提升、持平、下降的序列数和主要贡献片段，检查增益是否集中在少数片段。

### 6.3 用事件归因解释全程变化

当帧正式提交被 CLEAR 匹配，不能自动代表全程有效。需要同时比较：

- W 提交时的当前覆盖与原身份延续；
- 整段新增和失去的 GT 覆盖，及 FP、FN、IDSW 变化；
- 参考 B 恢复事件是否消失、由同 ID 提前延续替代，还是原覆盖真的丢失；
- 运行时间与额外 RGB 计算代价。

即时提交次数、GT 目标帧和整个预测轨迹的 FP/FN 使用不同计数单位，不直接混合。未匹配输出可按评测口径计 FP，但其视觉原因仍可能是背景、定位偏差、标注范围或其他问题；不要把离线 unknown 自动改标为背景。

本批耗时包含详细日志和同帧反事实策略计算，反映诊断实验的运行成本。它不能直接当作删去诊断记录后的最终部署延迟；若模块有效，再单独测量部署模式的速度。

## 7. 如何作出继续或停止的决定

HOTA 是本轮主要比较指标，IDF1、DetA、AssA 和 FP/FN/IDSW 用来说明收益来源与代价。不设置任意的“必须提升某个固定百分点”门槛，也不要求所有指标同时上升。硕士论文可以保留规模适中、可重复、机制解释清楚的改进，但必须如实报告代价和适用范围。

| 完整评测观察 | 后续决定 |
| --- | --- |
| 某策略在 B 与 BG 上均有可重复的指标改善，且错误代价可接受 | 保留为候选模块，整理该策略的消融和典型案例 |
| 在 B 上有效，在 BG 上增量消失或变差 | 研究组合关系，暂不宣称能给既有 BG 主基线带来第三项收益 |
| W1 优于 W0，但 W_H 显示历史可用性无变化 | 将作用归于运动阈值或排序，回到实际改变决策的案例解释 |
| W1 与 W0 输出一致，或 W2 与 W1 输出一致 | 如实报告等价，停止为制造差异而扩大权重或阈值搜索 |
| W3 只减少提交，却总体指标退化 | 停止当前相对竞争版本，保留负结果与失败机制 |
| 全部 W 策略的收益很小或代价抵消收益 | 停止当前固定设计，把后续资源转向已确认的主要错误类型 |
| 少数序列改善、另一些序列明显受损 | 先说明场景和错误差异，不用总体单个最好数字宣称稳健有效 |

本轮完整结果出来后，再决定是否需要人工扩充未知候选复核或修改设计。人工复核服务于解释与下一轮设计，不作为本轮完整运行的前置审批。
