# VT-Tiny-MOT 上的透视关联、遮挡更新与运动过程噪声

这里实现了三个可以单独开启的 BoT-SORT 扩展。对照使用服务器冻结的原生 BoT-SORT、YOLO11-M RGBT 检测结果和 RGB ReID 特征。每个方法在独立进程中回放同一批数据。原有的 B 恢复、LightGlue 自适应 GMC、找回后状态重估和 C2 在这些实验中均关闭。

## ③ 只改变关联的投影几何

使用上帧和本帧 RGB，屏蔽检测前景，在 4×4 网格提取背景角点并用双向光流验点。用棋盘格的一半网格拟合变换，另一半检验。候选包含六参数仿射和八自由度单应。矩阵须通过内点空间分布、角点位移、局部尺度、朝向与投影分母检查。与当时最好的较简单模型相比，留出点中位残差须下降至少 0.35 像素且至少 20%，80 分位残差最多上升 0.25 像素。均以原图像素计。

原生 SOF 始终负责 KF 状态传输。在状态传输之前保存各轨迹的预测框，将四角投到当前帧，再取轴对齐包围框与当前检测计算正向 IoU。双向组也把检测逆投影到上一视角，两个方向的 IoU 取算术平均。首次关联、低分二次关联和未确认轨迹关联均使用相同几何入口。RGB 外观融合与求解器沿用原版。只有通过检验的替代矩阵才进入该分支，其余帧用原生关联。首帧没有帧间估计。无未来关键帧、回填或离线平滑。[HomView-MOT，图 7 与公式 14](https://arxiv.org/html/2403.10830)

| 实验名 | 允许的替代配准 | 投影方向 |
|---|---|---|
| `affine_forward` | 仿射 | 正向 |
| `homography_forward` | 仿射、单应 | 正向 |
| `homography_bidir` | 同一组仿射、单应矩阵 | 双向 |

`perspective_quadrants.csv` 给出单应胜出帧的空间残差。在留出点上按四个象限计算水平和垂直有符号误差中位数，参考取通过几何检查的仿射，缺失时取原生 SOF。影像没有飞行姿态标注，象限残差只能描述空间误差的方向。单应选择与残差统计部分共用点集，最终效用以跟踪结果判断。

## ④ 已匹配低分框的遮挡更新

候选必须已通过原生低分二次关联，得分严格介于 0.1 与 0.5，且其轨迹上一帧确实得到观测、与其他活动轨迹观测框有交叠。用上一帧观测计算被覆盖的矩形并集占本框面积的比例，重复覆盖只计算一次。用当前预测框与已接受检测的 IoU 计算权重。原生更新后按下式调整包含中心、尺寸和速度的八维均值。

`m = m_prior + weight × (m_native_posterior − m_prior)`

| 实验名 | weight | 可检验的作用 |
|---|---|---|
| `bam_iou` | IoU | 所有组共用的拥挤触发条件下，只按当前一致性降权 |
| `bam_overlap` | IoU × (1 − 上帧所有交叠的覆盖比例) | 加入上帧拥挤程度 |
| `bam_bottom` | IoU × (1 − 上帧更低底边框的覆盖比例) | 只让底边比本框低超过 5 像素的框充当遮挡者 |

观测的置信度、类别、外观和后验协方差沿用原实现。这里的覆盖采用矩形并集。OA-SORT 中的高斯位置修正与遮挡感知关联不在本消融内。训练侧以相邻帧同一 GT 的检测中心误差检验底边线索。官方数据没有前后深度真值，按目标短边归一化的偏框只是代理量。[OA-SORT，第 4.1 节与表 4](https://arxiv.org/html/2603.06034v1)

## ⑤ 基于运动状态拟合 Q

在 Lost 轨迹的预测阶段添加平面随机加速度协方差 `q × G Gᵀ`。每一轴的位置系数为 1/2、速度系数为 1，每帧为一个时间步，尺寸和尺寸速度方向的增量为零。分别拟合常数 q 和运动相关 q。后者采用带界、带正则的对数线性模型，输入为上次观测后的目标速度除以目标尺度、目标尺度及常数项。尺度为框宽高几何均值。使用对数和截断，q 的范围约为 0.000006 到 16。失联期间固定使用上次观测的特征。R、原生状态转移和关联门限沿用基线。增量通过协方差和再观测时的卡尔曼增益影响状态。

拟合使用官方训练源序列中已有的 192 帧窗口和高质量检测—GT 配对，检测与 GT 的 IoU ≥ 0.30，最佳与次佳的间隔 ≥ 0.15。在至少 3 次连续匹配之后模拟 3、5、11、20、30 帧失联，用真实训练图像的 SOF 传输状态，同时计算终点中心高斯负对数似然。目标函数按序列与间隔平衡，每序列最多采样 160 个锚点。代码验证拟合组、训练侧留出组、官方测试组的母视频互斥。拟合后的参数保存在 `q_policy.json`。ACNTrack 使用学习型 Q 和 R，此实现只检验低维、可解释的 Q。[ACNTrack，Neurocomputing](https://doi.org/10.1016/j.neucom.2025.130811)

## 复现

服务器使用 `redetr` 环境，保留冻结的 `integrations/botsort_plus_v0_4_motion_blur/BOT-SORT-Plus-followup-c3e142e6`、跟踪缓存、官方 GT、原实验的训练配对、图像和 TrackEval。各路径与环境设置在 `settings.py`。在服务器实验目录运行以下命令。要生成独立的第二次运行，可提前建立新的输出目录，设置 `VT345_ROOT` 为该目录、`VT_INTEGRATIONS` 为原有 integrations 绝对路径，再调用本目录下的 `workflow.py`。

```bash
python -Bu workflow.py check
python -Bu workflow.py prep
python -Bu workflow.py motion
python -Bu workflow.py filter
python -Bu workflow.py score
python -Bu workflow.py probe
python -Bu workflow.py report
```

`motion` 运行原生及两类几何、遮挡消融，`filter` 读取已拟合的 Q 并运行两组过程噪声对照。每个方法先跑 DJI_0173_2、DJI_0277_2、DJI_0169_3，再跑全 30 段。`score` 在独立进程读取官方 RGB 坐标真值，重验输入、原生历史轨迹和子集与全量的输出一致性，生成全类别合并的 TrackEval 指标。`probe` 独立回放并统计双向代价在实际配对中的变化，同时逐序列复核其轨迹和配准。

## 事件指标的分母

- 失联覆盖按真实失联帧统计。用最后一次官方 CLEAR 匹配为轨迹确定 GT，仅保留本帧仍有该 GT 的观测。三组按序列、锚帧、锚检测、GT 和评估帧取交集。二维椭圆取卡方阈值 5.991465，使用预测位置协方差，面积计原图平方像素。NLL 省略对所有模型相同的常数。
- 找回评估要求断前及找回帧均获同一官方 GT，在共同事件中还要求找回检测相同。从找回帧到第 +3、+5、+10 帧逐帧检查原预测 ID。仅在窗口内 GT 始终有标注时计入对应分母。
- 低分评估要求上帧和当帧均是原 ID 匹配同一 GT，再对齐各方法本帧的检测行。共同事件按「原始检测是否比原生先验中心离 GT 更远」分层，各方法均使用原生分层。后续原 ID 率使用全部持续有标注的窗口，`shared_error` 只在各方法均保住原 ID 的同一批窗口比较位置误差。
- 总指标使用 TrackEval 的 `COMBINED_SEQ`。官方 30 段曾用于前序模型或门限选择，本轮结果按开发性全量消融解释。
